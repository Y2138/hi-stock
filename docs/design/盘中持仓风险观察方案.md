# 盘中持仓风险观察方案

## 目标

交易时段每 30 秒采样当前持仓、持仓所属行业板块和核心大盘指数，使用已配置的 `glm-5.3-flashX` 判断当前持仓风险。只输出简短风险状态，不执行交易，不创建 Agent 会话。

## 数据范围

- 历史背景只读取日线，最多提供最近 20 根日线。
- 当日走势读取本交易日已经采样的快照序列，模型同时获得全日摘要和最近 20 次采样。
- 相关持仓策略正文按当前策略文档提供，过长正文只保留有界片段并标明截断。
- 个股对应行业板块只使用数据库当前有效的扶摇行业板块关系，不由模型推断。
- 快照带数据源时间戳和服务端采样时间；数据缺失或过期时不得形成方向性判断。

## 执行边界

- 后台观察器独立运行，不使用 `job_run`、`job_run_output`、`chat_session` 或 `chat_message`。30 秒循环只在交易日交易时段启用；开盘前、午休和收盘后直接睡到下一观察窗口，休市日早盘只检查一次交易日历后睡到次日。
- 采样、模型分析和提醒投递互不阻塞；同一时刻最多一个模型分析调用。
- 模型不调用工具，服务端一次性提供持仓事实、当前每日计划、日线、当日采样、行业板块和核心指数上下文。
- 模型必须覆盖全部当前持仓，返回缺项或重复项时本轮不更新判断。
- 模型固定返回 `normal`、`watch`、`high`，以及可选关键位和不超过 60 字的盘面原因。

## 页面与提醒

- 持仓页显示盘中风险总览和持仓表风险列。
- 只显示当前风险、关键位和简短盘面原因，不显示每轮模型调用。
- 风险升级或关键位变化时进入个人提醒；相同风险状态去重，不重复通知。
- 盘中采样和最新判断保存在本机运行数据中，不进入可移植固定资产包。
