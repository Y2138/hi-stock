### 6.2 长任务状态

通用长任务可按实际需要定义状态；每日计划设计必须使用下列唯一状态机，不得另设同义状态。字段语义和“最新正式计划”资格继承 PRD 第 10.2 节，设计只补充页面呈现和操作细节。

| 状态 | 进入条件 | 展示 | 可执行动作 | 退出条件 | 是否可恢复 |
|------|----------|------|------------|----------|------------|
| 生成中 | 冻结输入后执行生成步骤 | 目标日、输入版本、阶段进度 | 查看；取消后进入已拒绝 | 待确认 / 部分成功/缺数据 / 失败 / 已拒绝 | 是 |
| 部分成功/缺数据 | 有可核验结果，但发布必需数据或覆盖不完整 | 成功项、缺失项、影响和最近有效值 | 补数据重算、拒绝；禁止发布 | 重算中 / 已拒绝 | 是 |
| 失败 | 无可复核草稿或任务不可恢复终止 | 失败阶段、错误、最近成功输入 | 重新发起、拒绝 | 新任务生成中 / 已拒绝 | 是 |
| 待确认 | 完整草稿通过发布门槛并冻结 | 草稿、证据、输入差异、风险 | 按 D4 确认、拒绝、重算 | 已发布 / 已拒绝 / 重算中；冲突时预览失效 | 是 |
| 已拒绝 | 用户拒绝、放弃部分/失败结果或取消运行 | 拒绝原因、原草稿/错误 | 复制为新任务 | 原任务终止 | 是 |
| 重算中 | 用户要求基于新输入重新生成 | 新旧输入差异、阶段进度 | 查看；取消后进入已拒绝 | 待确认 / 部分成功/缺数据 / 失败 / 已拒绝 | 是 |
| 已发布 | 确认、版本复核和发布事务均成功 | 正式版本、目标日、证据、确认记录 | 只读查看、发起新任务 | 已过期/被替代 | 是 |
| 已过期/被替代 | 目标日失效或同目标日新版本已发布 | 失效原因、替代版本入口 | 只读查看 | 终态 | 是 |

任务状态必须能在页面刷新或进程重启后恢复；不得因前端失联重复写入。只有目标日仍有效、未被替代的最新一个“已发布”版本有“最新正式计划”资格；其余状态一律没有。没有合格版本时显示“当前无正式计划”。D2-C 或 D2 未决时不能进入“已发布”。
