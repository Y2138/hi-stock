# 关注池信号复核方案

## 决策

复用各策略现有任务，统一执行新机会发现和本策略全部存量关注复核，不新增全池评分或清理任务。策略条件决定去留，不设跨策略通用质量分。

## 信号生命周期

- 满足正式条件：保留并刷新分析依据、数据日和有效期。
- 满足该策略接近候选标准：保留为待补信号，明确缺少的条件；不满足候选标准则退出。
- 明确不满足条件、已转为持仓或超过关注有效期：移除本策略信号，保留历史评估与工具审计。
- 未覆盖或数据不足：记录具体缺口、优先补齐，原信号不续期；数据不足不能冒充条件不满足。
- 新自动信号的信息有效期默认至下一已确认开市日，日历缺失时只认可数据日；这不延长或改变策略的买入窗口。旧条目已有明确期限的不延长；旧版无期限条目按原数据日补充期限。
- 过期的自动关注不再撑大当前列表；策略下一轮维护时结束没有有效来源的自动成员记录。

## 复核覆盖

波段扫描将本策略存量关注纳入样本复核，缺行情或指标的单独报告。两年结构反转分别判断行业条件和个股条件，行业数据不足不认定行业失效。波段和两年反转的结果数量限制不截掉仍符合条件的存量信号。价值错杀对当前排名范围逐股评估，旧标的明确不在有效排名范围时退出。铜策略沿用固定标的与原条件。

结构化扫描返回实际完成复核的代码及逐股缺口，关注维护不再凭“本轮没有出现在候选列表”批量删除。价值错杀、两年结构反转任务必须走统一结构化评估与关注写入链路。

夜间板块任务先读完整关注池，逐项复核所属策略的存量信号，提交已复核代码和具体缺口。缺覆盖的结果只能部分完成；禁止用空候选集合表示尚未执行的复核。补数据通过现有受控行情工具。

## 成员管理与隔离

成员明确区分人工管理与策略管理。新自动入池标的采用策略管理；人工新增、人工编辑的成员保留人工管理。自动补齐人工成员画像不改变其管理方式。

旧成员仅在具备明确自动入池标签和备注、无人工作业归因、无人工关注时转为策略管理，来源不明确的保留人工管理。最后一个有效策略信号退出后，自动成员结束生效并记录原因；人工关注、人工成员和其他有效策略信号受到保护。持仓独立评估，不删除持仓数据。

同日信号恢复可以重新激活成员，避免唯一键冲突。历史运行不得覆盖更新日期的评估结果；不同策略分别维护自己的信号。

## 验证与上线

使用独立测试库验证部分完成、具体缺口、不续期、过期退出、多策略隔离、人工保留、持仓独立、同日恢复和历史运行防覆盖。向前迁移增加管理方式与退出原因，并更新策略任务提示词。普通代码更新后重启服务应用迁移；不通过执行 Agent 任务验证，避免触发消息通知。
