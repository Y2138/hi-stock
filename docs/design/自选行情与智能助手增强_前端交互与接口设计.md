## 一、职责与边界

本文负责统一自选、行情页、市场结构、图表标注的 HTTP 契约、页面信息架构和交互状态。

**本文不改变**

- Agent 工作区、主题系统、消息中心和主布局的既有职责。
- 策略角色、持仓、账户和策略发布门禁。
- `market_bar` 与盘中采样的数据语义；数据模型见[数据模型与迁移设计](自选行情与智能助手增强_数据模型与迁移设计.md)。

近实时频率、SSE 生产和指标计算由[行情运行时与指标设计](自选行情与智能助手增强_行情运行时与指标设计.md)定义。

## 二、页面信息架构

### 2.1 自选页

系统视图与用户分组分开呈现：

```text
自选
├─ 全部
├─ 关注
├─ 板块
│  ├─ 行业
│  ├─ 概念
│  ├─ 区域
│  └─ 特色
└─ 自定义分组
```

- “全部”“关注”“板块”是动态视图，不写入 `watchlist_group`，不可重命名或删除。
- 同一标的在多个板块视图出现只是查询投影，不产生重复 `watchlist_entry`。
- 每行展示资产类型、近实时或最近收盘、行情时间、新鲜度、策略角色徽标和能力不足说明。
- 删除自选前展示仍存在的持仓和策略角色；确认删除不级联修改这些关系。
- D1 若采用建议方案，原标的池导航保留一版只读“策略角色”入口，之后仅移除导航，底层 `pool_membership` 永久保留。

### 2.2 行情页

页签为：近实时对比、历史 K 线、市场结构。URL query 保存当前 tab、主标的和对比 codes，刷新后恢复上下文。

**近实时对比**

- 先展示行情时间、新鲜度和覆盖率，再展示曲线。
- 主标的之外最多选择 3 个对比项。
- 按前收归一化；前收缺失时禁用归一化并说明原因。
- 缺口为 null 且不连线，不使用旧值补成连续曲线。

**历史 K 线**

- 指标开关从 API 返回的可用指标生成。
- `untrusted` 时禁用指标并显示复权或缺口原因，原始 K 线仍可查看。
- 画线工具仅在图表 controller ready 且数据可用时启用。

**市场结构**

- 支持涨停、跌停、炸板、连板天梯和龙虎榜切换。
- 顶部固定显示目标交易日、来源截止时间、完整/部分状态和覆盖页数。
- partial 不显示绿色“正常”；用户可以查看缺失页或数据集说明。

## 三、HTTP 契约

沿用现有 `{data}` / `{error:{code,message}}`、1 MiB JSON 上限和仅绑定 127.0.0.1 的规则。

### 3.1 标的、板块和自选

| 方法与路径 | 契约 | 兼容策略 |
|---|---|---|
| `GET /api/instruments/search?q=&kind=&asset_type=&remote=` | 本地目录和可选远程候选，返回能力与 `persisted` | 旧 `/api/instruments` 保留一版 local-only 别名 |
| `GET /api/boards?type=&q=` | 板块目录、行情状态和自选交集 | 新增 |
| `GET /api/boards/:code/constituents?as_of=` | 目标日有效成分、同步截止和 gaps | 早于历史启用日返回 unavailable |
| `GET /api/watchlist?view=&board_code=&group_id=` | all/focused/board/custom 统一视图 | 返回 `schema_version=2` |
| `POST /api/watchlist/entries` | code、focused、note、group_ids；缺档案时精确远程解析 | 新 UI 和 Agent service 使用 |
| `PATCH /api/watchlist/entries/:id` | focused、note、sort | 新增 |
| `DELETE /api/watchlist/entries/:id` | 删除自选，不删除策略角色 | 旧 items 端点一版内返回弃用说明 |
| `PUT/DELETE /api/watchlist/entries/:id/groups/:groupId` | 维护自定义分组关系 | 替代旧 item 移组语义 |

统一自选 service 是页面与 `watchlist_write` 的唯一写入口。`add` 幂等创建，已有条目只补充显式字段；分组关系通过独立端点维护。Agent 写入预览的状态指纹覆盖 entry、分组关系和 instrument 当前状态，避免旧提案覆盖用户刚完成的编辑。

### 3.2 行情、指标和市场结构

| 方法与路径 | 契约 | 限制 |
|---|---|---|
| `GET /api/market/quotes?codes=` | 最新快照、来源、行情时间和新鲜度 | 最多 200 codes |
| `GET /api/market/realtime-series?codes=&trade_date=` | 归一化采样与 gaps | 主标的加最多 3 个对比项 |
| `POST /api/market/realtime/subscriptions` | client_id、codes、view，90 秒 TTL | 只影响内存优先级 |
| `GET /api/market/realtime/stream?codes=` | `quote_batch` SSE 和 heartbeat | 不承诺历史重放 |
| `GET /api/market/bars?...&include=ma,macd` | K 线、指标、版本和 status | 兼容原 bars；过渡期开关选择 MA 来源 |
| `GET /api/market/structure?date=&dataset=&filters=` | 特色数据分页结果、覆盖和 gaps | dataset 使用白名单 |

页面进入近实时页时先 GET latest 和当日 series，再建立 SSE。断线重连先重新 GET，避免客户端错过批次后继续显示为实时。

### 3.3 图表标注

| 方法与路径 | 契约 |
|---|---|
| `GET /api/chart-annotations?...` | 按主标的、视图、复权和对比上下文查询 |
| `POST /api/chart-annotations` | 新建水平线、趋势线或文字标注 |
| `PATCH /api/chart-annotations/:id` | 携带 `expected_version` 乐观更新 |
| `DELETE /api/chart-annotations/:id` | 软删除；批量清空由页面二次确认 |

### 3.4 Agent 指标摘要

`GET /api/agent/metrics/summary?from=&to=&model_id=` 只返回 token、成本、时延、工具轮次和状态聚合，不返回提示词或工具结果正文。首期仅本机设置页使用。

### 3.5 稳定错误码

| 错误码 | 页面行为 |
|---|---|
| `REMOTE_SEARCH_UNAVAILABLE` | 保留本地结果并提示远程搜索暂不可用 |
| `CAPABILITY_UNSUPPORTED` | 展示可关注但该能力不支持，不反复重试 |
| `PROVIDER_RATE_LIMITED` | 展示延迟状态和可重试时间 |
| `BOARD_SYNC_PARTIAL` | 保留上一完整成分并显示 gaps |
| `QUOTE_STALE` | 显示旧值、行情时间和 delayed，不伪装实时 |
| `INDICATOR_UNTRUSTED` | 隐藏派生线，保留原始 K 线 |
| `ANNOTATION_VERSION_CONFLICT` | 提供服务端版本，让用户选择保留本地副本或覆盖 |

底层 429、供应商响应体和完整请求 URL不得直接透出。

## 四、图表控制器与标注层

现有 `KlineChart.vue` 需要抽出受控控制器，避免页面直接持有完整 ECharts 实例：

```typescript
interface MarketChartController {
  toData(pixel: [number, number]): { time: string; value: number } | null;
  toPixel(anchor: { time: string; value: number }): [number, number] | null;
  onViewportChange(listener: () => void): () => void;
  getContext(): ChartContext;
}
```

`ChartAnnotationLayer` 使用 ZRender 绘制图元，服务端只保存数据坐标：

1. 缩放、resize、主题变化和数据刷新后，都从数据锚点重新计算像素。
2. 拖动期间只更新本地草稿；pointerup 后 PATCH。
3. 保存失败时不丢草稿；版本冲突默认不覆盖服务端版本。
4. 撤销/重做只保存当前会话操作，最终状态和软删除写数据库。
5. 近实时与 K 线可以共用标注层，但 context、坐标单位和复权口径不同，禁止自动跨上下文套用。

D5 若确认首期范围，只注册 horizontal、trend、text 三种标注；Schema 通过类型白名单扩展，不为未实施类型预留自由 JSON。

## 五、页面状态与反馈

| 状态 | 含义 | 页面反馈 |
|---|---|---|
| `loading` | 首次请求中 | 保留骨架或局部加载，不清空稳定导航 |
| `empty` | 请求完整但无数据 | 给出空态原因和可执行入口 |
| `delayed` | 有旧值但超过新鲜度阈值 | 显示旧值、行情时间和延迟标识 |
| `partial` | 批次只有部分代码或分页 | 显示 coverage 和 gaps |
| `stream_disconnected` | SSE 断开 | 保留最后值，重连前不标实时 |
| `break` | 交易日午休 | 显示午休和最后行情时间 |
| `closed` | 非交易日或已收盘 | 显示最近收盘，不触发持续重连提示 |
| `unsupported` | 资产可检索但能力不足 | 保留关注能力，禁用对应行情入口 |
| `untrusted` | 指标输入口径不可靠 | 展示原始行情，隐藏派生值 |

轮询成功不产生全局 success。只有断流、恢复、保存标注、加入/删除自选等用户可感知事件使用现有消息中心。

## 六、交互细节

### 6.1 搜索和加入自选

- 输入按代码前缀、完整代码、名称和 alias 检索；结果同时显示类型、交易所和能力，解决同名消歧。
- 本地结果不足时才展示远程候选；`persisted=false` 明确表示尚未进入本地目录。
- 加入动作提交标准 code，由服务端重新精确解析，不信任候选对象中的自由字段。
- 网络失败时保留搜索文本和本地候选，不产生半成品 entry。

### 6.2 分组与删除

- 拖动或菜单移组只更新 membership，不移动或复制 entry。
- 删除自定义组时提示“只删除分组，不会删除自选标的”。
- 删除自选时若仍有持仓或策略角色，预览中逐项列明；用户确认后也只删除自选关系。

### 6.3 可访问性和窄屏

- 画线工具、页签、分组操作和错误恢复必须可用键盘到达并有可见焦点。
- 颜色不是新鲜度、涨跌或错误状态的唯一表达，同时提供文字或图标。
- 在 1280×720 和窄桌面下，表格允许列优先级折叠，不允许主布局出现横向溢出。

## 七、计划验证

| 验收行为 | 计划验证方式 | 观察信号 |
|---|---|---|
| 本地和远程搜索消歧 | 服务测试覆盖代码、名称、同名、`.TI`、`.OF` 和远程失败 | 类型、能力与 persisted 正确 |
| 自选唯一关系 | 浏览器执行加入、关注、多组、删组和删自选 | 同标的一条 entry，删组不删 entry |
| 板块动态视图 | 一个标的属于多个板块并切换日期 | 视图投影正确，无重复持久化 |
| 近实时断流恢复 | 模拟 SSE 断开、延迟和 partial | 状态不误报实时，重连后重新 GET |
| 对比归一化 | 固定前收、停牌和不同采样时点 | 百分比正确，null 不连接 |
| 画线持久化 | 浏览器拖动、缩放、主题、刷新和版本冲突 | 数据锚点不漂移，冲突不覆盖 |
| 市场结构分页 | 完整、partial、空和非交易日数据 | 截止时间、覆盖与缺口始终可见 |
| 前端回归 | typecheck、生产构建和两种视口截图 | 无横向溢出，主题、焦点和动效可用 |

## 八、专题风险与回退

| 风险 | 缓解 | 回退 |
|---|---|---|
| 统一自选迁移后旧页面语义错位 | 旧端点只读映射新 service，并返回弃用标记 | 关闭 `UNIFIED_WATCHLIST_READ`；正式新写入后需恢复迁移前快照 |
| 图表标注随复权或对比项漂移 | 上下文哈希包含复权和排序后的对比集合 | 隐藏不匹配标注，允许复制到新 context |
| SSE 断线仍显示“实时” | 新鲜度由 quote_time/fetched_at 计算，断线立即变更状态 | 关闭实时入口并回到最近收盘展示 |
| 页面状态过度使用全局提示 | 明确局部状态表，成功轮询不提示 | 关闭相应功能开关，不影响其他工作台页面 |
