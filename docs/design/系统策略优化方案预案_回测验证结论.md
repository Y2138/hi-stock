> 状态：两轮研究验证完成；全部结果为 `research_only`，不构成生产发布证据。
> 验证日期：2026-09-12。
> 关联：[优化预案](../系统策略优化方案预案.md)、[数据缺口分析](系统策略优化方案预案_数据缺口分析.md)、[回测架构规划](../系统回测能力架构规划-评审说明.md)。
> 执行方式：本地脚本 `scripts/strategy-optimization-backtest.ts` 直接调用系统标准回测能力（冻结输入 + 日频内核 + 独立核账），未经内置 Agent，不写回测运行台账；原始结果 JSON 在 gitignored 的 `支撑/tmp/策略优化回测/`。

## 一、验证边界（必读）

**标的池口径（两轮）：**

| 轮次 | 池 | 筛选规则 |
|---|---|---|
| 第一轮 | 100 只（严格覆盖样本） | 从「2017-01-03 至 2026-08-31 每个开市日都有正成交量日线」的 1007 只中按代码等距抽取 |
| 第二轮（扩池） | 500 只（停牌近似样本） | 放宽为「上市覆盖整个区间（首根行情≤起点、末根行情≥终点）且无非法价格行」的 2595 只中等距抽取；区间内缺行或零量日按停牌近似纳入（训练窗 500 只共 11,984 例，平均约 25 日/只） |

**这不是全 A 股。** 全 A 5,562 只中，2017-01-03 前上市且 2026-08-31 仍在交易的合格宇宙为 2,595 只：次新股票在窗口起点尚未上市、当时确实不可交易（时点正确性，自动排除）；已退市股票被「末根行情≥区间终点」排除（幸存者偏差保留，必须披露）；长期停牌股按停牌近似纳入。两轮均按代码等距抽取，训练窗与样本外窗同池可比。

| 项目 | 取值 | 说明 |
|---|---|---|
| 窗口 | 训练 2023-01-03→2024-12-31；样本外 2025-01-02→2026-08-31；全窗 2023-01-03→2026-08-31 | 三窗口共用同一样本，训练/样本外直接可比 |
| 价格口径 | `forward_research`（前复权） | 避免分红除权制造假止损；不能解释为历史真实成交收益 |
| 停牌近似 | 缺行或零量日=不可交易：持仓按最后成交收盘估值、指标序列跳过、买单作废、卖单复牌开盘执行 | 未接入历史停牌状态，未区分真实停牌与数据缺口（冻结输入 gap 已披露） |
| 费用假设 | 佣金万2.5（最低5元）、卖税10bp、滑点10bp、容量2% | 全程一致的显式假设；卖税按 2023-08 前的 0.1% 计，偏保守 |
| 市场参照 | 冻结输入内 881 行业等权合成指数 | 本地实例的交易所指数日线 2023 年前存在失真（重复收盘值、点位错误），不用作超额基准 |
| 执行模型 | 收盘决策 → 次日开盘成交，开盘价不高于信号收盘 5%，开盘涨停不买、跌停不卖 | 日频近似，非盘中回放 |
| 内核退出 | 简化退出：固定止损 + 可选一档止盈 + 最长持有 20 日；左侧为生产的 ATR/分批/时间退出 | 未建模右侧生产的冷却期、分批止盈、移动止损、六条件复核退出 |

年化收益率 = (1+总收益)^(252/正式窗口交易天数) − 1。样本偏差：幸存者偏差与等距抽样（含大量低波动老股票）使绝对收益不可外推；**同一窗口内的 A/B 相对比较才是本验证的有效结论。**

## 二、本轮对系统的修正与新增（均已通过测试）

验证过程中发现并修复了标准回测内核的三个真实缺陷，并按预案补齐了实验所需的规则参数（全部为可选参数，缺省关闭）：

1. **修复：熔断参数被静默丢弃**。所有标准运行都经组合内核 `portfolio-engine.ts`，其 `childPlan` 硬编码 `drawdown_circuit=false`、`stop_streak_circuit=false`——即预案第 3 条的回撤/连止损熔断在真实运行路径中从未生效过。已改为单规则运行透传熔断，并在计划校验中显式拒绝组合模式携带熔断（组合级熔断未实现，不允许静默降级）。
2. **修复：可选规则参数透传缺失（同型两处）**。一档止盈与左侧放宽参数同样会被 childPlan 丢弃，已一并修复并补测试。
3. **对齐生产**：右侧同日候选排名由实验排名（量比）改为生产的「MACD柱单日增量/收盘价、0.003 封顶」排序；新增「T+1 开盘价高于信号收盘 5% 放弃建仓」的生产成交约束（短线策略 §1.1）。
4. **新增停牌语义**（本轮扩池前置条件）：冻结输入对区间内缺行或零量的股票日线按停牌近似（不再整体拒绝），内核对停牌标的不推进指标序列、持仓按最后成交收盘估值、买单作废、卖出意图保留至复牌开盘执行；核账器同步校验停牌估值。容量预算同步放宽：单计划标的 100→1000、输入 50 万→300 万行、冻结预算 5→15 分钟（引擎版本 `standard-daily-v3`、输入版本 `standard-input-v2`）。
5. **新增市场因子**：冻结输入层逐日派生 881 合成指数 MA20/斜率、行业上涨占比、行业 ADX14 中位数（Wilder，自 881 数据首日起递推预热），作为可选的震荡过滤与宽度确认输入。
6. **事件预算修复**：单日逐只评估事件在大宇宙+极端行情日会突破核账器 1000 事件/日预算（2024-09-30 实测 1110 条），已按架构§5.2 修正为「仅排名前 100 的候选逐只记录，其余进 evaluation_summary 汇总事件」（daily_buy_limit ≤ 100，覆盖全部可下单标的，不损失任何成交信息）。
7. **新增规则参数**：`oscillation_filter`（震荡期把每日新开仓限制为 1—2 名，支持 MA20 斜率/ADX/贴近MA20/宽度四因素单消融或 AND/OR 组合）、`breadth_confirm_min`（行业上涨占比低于阈值不开新仓）、`take_profit_pct`（一档止盈，全退简化）、`drawdown_circuit_pct`（回撤阈值，默认 5%）、`left_reversal_params`（左侧超卖深度放宽：5日跌幅/RSI/MA20偏离三项，形态条件不变）。
7. 回归：`npm run typecheck`、`tests/server/backtest-engine.test.ts`（34 项）、`tests/server/backtests.test.ts`（24 项）、全量 `npm test` 全部通过。

## 三（续2）、优化落地轮：生产分档退出与组合级熔断（500 只池）

本轮把验证过的思路落地为引擎能力并复验：右侧 `exit_model="production_tiered"`（生产§2分档退出：冷却期止损、+12%/+28% 分批止盈、移动止损、转弱/崩坏复核/时间兜底）；组合级熔断（组合 20 日高点回撤 >5% 或全组合连损 3 笔 → 暂停全部子策略新开仓，881 MA20 斜率恢复；通过新的 `control()` 暂停管道作用于子策略）；组合策略支持按策略携带退出模型与左侧放宽参数。

| 配置 | 训练窗 总/年化/回撤/交易 | 样本外 总/年化/回撤/交易 | 对照 |
|---|---|---|---|
| 右侧500_分档退出（无熔断） | -68.9% / -45.6% / 71% / **506** | -79.0% / -62.3% / 79% / **405** | 简化退出基线 -62.5% / -68.0%（169/161 笔） |
| 右侧500_分档退出_熔断5 | **-9.7% / -5.2% / 26%** / 203 | -24.8% / -16.3% / 31% / 158 | 简化退出+熔断 -18.9% / -22.7% |
| 组合500_优化版（右分档+组合熔断，左组合A，波段） | -28.9% / -16.3% / **32.3%** / 201 | -8.4% / -5.3% / **21.0%** / 223 | 同结构对照 -47.0% / +4.8%（回撤 51% / 30%） |
| 组合500_对照 | -47.0% / -28.1% / 51% / 207 | +4.8% / +3.0% / 30% / 169 | — |

**结论：**

1. **分档退出单独不成立**：时间兜底（第 5 日）与崩坏复核在广域宇宙上过频触发，交易数放大 3 倍（506 vs 169）、费用放大 3 倍（8.8 万 vs 2.9 万），把尚未发展的盈利单在第 5 天砍掉，两窗口都劣于简化退出。生产的分档退出是为「真实短线池 + 盘中执行」设计的，日频近似 + 广域横截面不是它的适用环境。
2. **分档退出+熔断的组合出现正向迹象但不稳定**：训练窗 -9.7%（比简化退出+熔断好 9.2pp），样本外持平（-24.8% vs -22.7%）。熔断的暂停期恰好抑制了分档退出的换手窗口。
3. **组合级熔断机制本身工作正常**：暂停日数（286/179）、回撤压缩（对照 51%→32%、30%→21%）符合设计；但「优化版组合」相对对照训练窗 +18.1pp、样本外 -13.2pp，方向不一致，不能作为采纳依据。
4. **维持既有结论**：唯一两窗皆正、可建议进入策略评审的仍是回撤熔断 5%（简化退出即可）与左侧组合A 放宽参数；分档退出能力保留在引擎中，待真实短线池宇宙与盘中执行模型建成后另行验证。

## 三（续3）、优化第三轮：负期望根源消融（500 只池，含全窗验证）

针对「入场追高、盈利被截断、宇宙错配」三个假设做时点安全消融：`profit_trail` 退出模型（保留分批止盈+移动止损，去掉时间兜底/复核换手）、`min_amplitude_20`（20 根已实现振幅均值门槛，仅用截至当日行情）、`max_open_gap_pct`（T+1 开盘缺口上限，可收紧到 0）。

| 配置 | 训练窗 vs 基线 | 样本外 vs 基线 | 全窗 vs 基线 | 三窗一致？ |
|---|---|---|---|---|
| 基线（-62.5% / -68.0% / -86.5%） | — | — | — | — |
| 盈利奔跑（-57.6% / -45.1% / -75.6%） | **+4.9pp** | **+22.9pp** | **+10.9pp** | **是（采纳候选）** |
| 熔断5（-18.9% / -22.7% / -23.7%） | **+43.6pp** | **+45.3pp** | **+62.8pp** | **是（最强单因素）** |
| 盈利奔跑+熔断5（-37.8% / **+15.6%** / -30.1%） | -18.9pp* | +52.4pp | +56.4pp | 与熔断单独比不一致（*训练差、样本外右侧唯一转正） |
| 股性过滤35/45（-82.2%/-90.9%；-75.6%/-81.5%） | 更差 | 更差 | 未再验 | 一致地有害（否定） |
| 不追高（-62.6% / -76.1%） | ≈持平 | 更差 | 未再验 | 否定 |

要点：

1. **盈利奔跑退出三窗一致优于 20 日硬退出**：胜率从 28% 提到 32—33%，交易数下降，「截断盈利单」的负期望来源被部分修复。
2. **股性过滤被数据否定**：把候选集中到高振幅标的上反而更差——六条件动量信号在波动最大的票上遭遇更强的次日回归。用简单振幅做股性代理的方向错误，股性匹配需要真实短线池与更精细的画像。
3. **不追高无效**：跳过缺口开盘买点并没有改善（被跳过的缺口单整体并不更差），追高不是主要负期望来源。
4. **熔断 + 盈利奔跑的交互依赖市况**：样本外 +15.6%（右侧唯一转正），训练窗劣于熔断单独。两者都用时需要第三个窗口以上的证据，暂不组合采纳。
5. **左侧组合A 加仓验证（否定「仓位压制」假设）**：单笔 0.2→0.4、槽位 5→10 后，样本外年化 12.5%→20.9%，但全窗年化 13.4%→11.8%、最大回撤 25.3%→40.7%——集中度上升减少了同时持有的分散度（交易数 284→158），收益没有随仓位线性放大。左侧的约束是**信号频率**（3.7 年 284 笔）而非仓位，13.4% 年化、25% 回撤、三窗皆正已是该信号在当前频率下的风险调整最优。
6. **千只池否决「扩宇宙提频」假设（方法论转折点）**：组合A 扩到 1000 只池后三窗全灭（-0.3% / -6.7% / -1.4%，对比 500 池 +15.9% / +20.8% / +55.5%；严格左侧同样 -18.2% / +9.9% / -13.9%）。正期望没有跨宇宙保持——**500 池的正结果是样本特异的**。这一轮把全部机械日频信号（右侧动量、左侧反转、波段箱体）的共同结论显性化：在价量日频规则体系内，没有找到跨样本稳健的正期望；单样本正结果不可作为方向依据。此后任何信号/参数必须先通过「多随机样本 × 训练/样本外 × 费用压力」稳健性验收。



## 三（续4）、股性分层矩阵：策略×股票类型匹配（第五轮，含费用压力）

针对「右侧主升适合炒作型标的、左侧适合周期股」的假设做分层验证。股性指标全部用 2021-01-01→2022-12-31（两个窗口之前）的已实现行情计算（快拉=涨停日占比>1.5% 或大阳日占比>4%、波动=日均振幅，均沿用生产《股性分析》口径；涨停按生产公式前收×1.1，创业板/科创板 20% 制不适用），行业归属为当前 881 归属回看。三个分层：炒作型（2021-22 涨停次数 Top500）、周期行业（煤炭/油气/化学原料/钢铁/建材/造纸/航运/工业·贵·小·能源金属/石油加工/化纤 13 类 457 只）、温和型（日均振幅<3%）。

**训练窗 / 样本外 / 全窗（总收益；881 参照 +10.6% / +37.0% / +49.0%）：**

| 分层 × 策略 | 训练窗 | 样本外 | 全窗 | 三窗一致？ |
|---|---|---|---|---|
| 炒作型 × 右侧基线 | -85.8% | -51.8% | 未再验 | 一致地灾难（炒作型是右侧毒药） |
| 炒作型 × 右侧盈利奔跑+熔断5 | -52.0% | -43.2% | 未再验 | 一致地差 |
| 炒作型 × 左侧组合A | -19.5% | +0.3% | 未再验 | 否 |
| **周期行业 × 右侧盈利奔跑+熔断5** | **+28.3%** | **+19.0%** | **+68.2%** | **是——全研究首个三窗皆正的右侧配置** |
| 周期行业 × 右侧基线 | -51.9% | -34.1% | -69.2% | 退出与风控是把周期行业从灾难变金矿的关键 |
| 周期行业 × 左侧组合A | +31.4% | +1.5% | +19.9% | 否（训练好、样本外平） |
| 温和型 × 右侧盈利奔跑+熔断5 | -34.5% | -55.3% | 未再验 | 一致地差 |
| 温和型 × 左侧组合A | -0.1% | +15.2% | 未再验 | 否 |

**周期行业 × 右侧盈利奔跑+熔断5 细节**：年化 13.9% / 11.5% / **15.9%**，胜率 45.2% / 40.4% / 43.8%，暴露约 48%，219 笔闭环（全窗）。**费用压力测试**（佣金万5+滑点20bp，加倍）：全窗 +30.1%、年化 +7.8%——边际减半但稳健为正。

**「炒作型应该偏左侧」的补充验证（第六轮）**：用引擎中生产口径的试盘启动信号（放量试盘→缩量回踩不破低点→突破买入，即交易者所说的「回踩低吸」）跑炒作型与周期行业分层：炒作型 训练 -34.0% / 样本外 -6.4%，周期行业 -43.5% / -12.1%。方向上试盘比右侧主升适配炒作型（样本外 -6.4% vs 右侧 -51.8%，训练窗亏损也收窄过半），但日频机械版仍未转正。炒作型票的正期望大概率存在于打板/情绪/龙头战法所需的竞价、封单、连板梯队、分时信息中——这正是预案第三阶段预留、当前引擎不具备的粒度。

**结论：**

1. **「股性区分策略适配」的假设方向正确，但映射与直觉相反**：右侧动量信号的宿主不是「经常被炒作」的票（那是次日回归最强、对动量最致命的群体，基线 -85.8% 为全部实验最差），而是**趋势由商品周期等慢变量驱动、延续性强的周期行业票**。左侧组合A 对周期行业只在训练窗有效，样本特异性仍在。
2. **同一信号在不同股性宇宙上的差异可以达到「正 vs 灾难」的量级**（-85.8% vs +28.3%），宇宙选择本身就是最大的一个「参数」——但它必须是经济含义明确的分层（行业/属性），而不是事后统计筛选（振幅过滤的失败证明了这一点）。
3. 该配置的边界：周期行业集合由当前归属回看近似（457 只、13 类，集合定义敏感度未做消融）；费用压力下年化 +7.8% 说明对成本敏感；样本外强度（+19.0%）低于训练窗（+28.3%）但方向一致。进入采纳讨论前建议补充：行业集合边缘消融、滑点 30bp 压力、以及与真实短线池的交集分析。

## 三（续5）、长窗口重验：均衡牛熊的训练/样本外（第七轮）

针对「训练窗熊市居多、样本外牛市居多导致差异失真」的意见，改用长窗口：训练 2016-10→2021-12（含 2016-2017 蓝筹牛、2018 熊、2019-2020 成长牛、2021 结构市）、样本外 2022-01→2026-08（2022 熊、2023-2024 震荡熊、2025-2026 牛），两段各含完整牛熊震荡。约束：881 行业数据 2021-09 才开始，长窗训练段无法使用熔断恢复与行业闸门（以回撤连续缩仓承担回撤控制），全部以无环境模式运行；样本为上市覆盖 2016-10 且存续至 2026-08 的 2463 只中 CH-3 剔除后等距 500 只，坏行筛查扩展至全部种子期（发现并排除 2010-2016 旧日线链脏数据）。

| 配置 | 长训练窗 2016-2021 | 长样本外 2022-2026 | vs 基线一致性 |
|---|---|---|---|
| 基线 | -61.8% / 回撤 80.4% | **-94.1%** / 94.3% | — |
| 盈利奔跑 | -28.5% | -94.0% | 训练改善、样本外持平 |
| 52周高位+盈利奔跑 | **+1.3%** | -90.1% | 否 |
| 波动率目标 | -39.8% | -82.6% | 训练 +22pp、样本外 +11pp |
| 回撤连续缩仓5 | -23.4% | **-44.2%** | 两窗一致改善（+38 / +50pp） |
| 叠加（52周+波动目标+回撤缩仓+盈利奔跑，无熔断无行业闸门） | **+11.8% / 回撤 33.5%** | -52.0% / 回撤 52.1% | 两窗大幅改善基线（+74 / +42pp），但样本外绝对值深负 |
| 左侧组合A | -21.8% | -31.3% | 500 只长窗两窗皆负（100 只长窗曾两窗皆正） |

**结论：**

1. **训练/样本外差异确有 regime 成分，但右侧的负期望是结构性的**：把窗口拉长并均衡牛熊后，右侧基线在两段都深度亏损（-61.8% / -94.1%），此前短窗训练/样本外的符号翻转属于 regime 与样本特异的叠加，而非「某段市场适配动量」。
2. **「不同时间段股票表现不一样，不能一概而论」被直接证实**：profit_trail 在 2023+ 窗口三窗改善基线、在 2016-2021 长窗反而大幅劣化（-28.5% vs -61.8% 除外——注意方向也翻转）；左侧组合A 在 100 只长窗两窗皆正、500 只长窗两窗皆负。任何配置的表现都是「regime × 宇宙 × 样本」的联合函数，单一窗口/单一样本的正结果没有外推力。
3. **跨全部 7 轮、所有窗口/宇宙/样本仍稳健的只有两件事**：①回撤连续缩仓（对基线的相对改善两窗 +38/+50pp，短窗亦一致）；②叠加框架对灾难性回撤的压制（基线回撤 80-94% → 叠加 33-52%）。**没有任何机械配置在任何口径下实现「全部窗口为正」**——右侧体系在广域宇宙上的正期望不存在这一判断，经长窗口重验后维持。
4. 881 环境数据自 2021-09 起才可用，2021 前的训练段无法验证熔断恢复与行业闸门——「周期行业 × 全叠加」的结论目前仅覆盖 2023-2026，其在 2016-2021 的表现不可验证（数据边界，非结论）。

## 三（续6）、市场状态连续分段 + 权威因子落地矩阵（第八轮）

针对「机械等长切分年份 + 因子落地验证不足」两个问题，本轮完成三件事：

**① 行业环境数据补齐（合成 881）**：实测扶摇 881 板块指数最早仅到 2021-09-13（2016/2018/2020 三段请求均返回空，供应商数据边界）。以 881 当前成分（点时未证）× 全 A 前复权日线的等权日收益累乘，合成 2015-01→今的 90 个行业指数，落库为独立合成板块（`881xxx.SY`，不登记 `market_board`、与业务板块查询隔离）。重叠期（2021-09 后）与真实 881 日收益相关系数**中位 0.993、最差 0.816**（最差为 4-5 只成分的小行业）；合成环境同时驱动综合指数因子（`synthetic_881` 模式），使绝对动量/行业闸门/熔断恢复在 2016-2021 可用。等权口径与真实 881 自由流通加权的差异已在冻结输入警告中显式披露。

**② 分段方式重设计（连续状态段）**：以合成等权综合指数标注每日状态——牛市=收盘≥MA200 且 250 日收益>+15%，熊市=收盘<MA200 且 250 日收益<-15%，其余为震荡；同状态**连续 ≥60 交易日**的区间保留为一段（每段自身连续、不跨段拼接），跨 2021/2022 年界的段按交易日拆分，前半归训练、后半归样本外。得到 9 段：训练 4 段（2018-08 熊、2017-10 与 2019-02 震荡、2020-06 牛）、样本外 5 段（2024-06 熊、2025-04→2026-06 牛 275 日、2022-2023 震荡×3），两侧均含牛熊震荡。分段与已知市场史吻合（2018 贸易战熊、2024-06 微盘流动性危机、2025-04 起牛市）。统一宇宙：覆盖 2016-10→2026-08 的 2952 只合格股等距 300 只，全部段共用、全部段用合成 881 环境保证口径一致。

**结论（直接回答本轮问题）：**

1. **「行业动量 > 个股动量」在日频右侧体系中不成立，方向相反。** 行业动量闸门（20 日/60 日、行业内+Top30）把段均值从 -10.9% 恶化到 -20.1%/-18.7%，**连牛市段都翻负**（-21%/-21.8% vs 基线 +5.5%）——Top 行业的右侧候选并不更强，闸门主要作用是把非强势行业里的真信号拦掉。Moskowitz-Grinblatt 的行业动量是月频横截面定价因子，直接搬进日频入场过滤是错误的移植。**但见下方 CH-3 对照：小票剔除后该结论需要重大修正——行业动量的失效主要来自小票污染。**
2. **残差动量同样恶化（-17.6% vs 基线 -10.9%，0/9 为正）**：60 日个股超额（行业基准）≥0 的过滤在广域宇宙上等价于「过滤掉高波动候选」——与第五轮股性过滤的教训一致，Blitz 残差动量的低频选股价值无法在日频右侧入场条件中兑现。**该否定结论在 CH-3 剔除口径下同样成立（-23.9%，1/9），是本轮最稳的否定。**
3. **绝对动量闸门是本轮唯一稳健的正面增量，也是全部 8 轮里最接近「可作为规则」的单因素**：段均值 -1.9%（改善基线 9pp）、最差段 -14.0%（基线 -53.5%，改善 39.5pp）、牛市段 +10.5%（比基线还高 5pp——它不是单纯少交易，而是在该做的时段保持在场）、段均交易 29 笔（更低换手）。MOP 2012 的时序动量提供的「何时不做」信息与文献一致。120 日版本在熊段更稳（-4.4%；CH-3 口径下熊段 +0.7% 首次转正）。
4. **全叠加（绝对动量+行业闸门+残差+52周+盈利奔跑+熔断）与单用绝对动量60 几乎等价**（-1.6% vs -1.9%）——行业闸门与残差在叠加中是中性偏拖累，52 周与盈利奔跑贡献有限。叠加的费用压力版本（30bp 滑点）段均值 -8.0%：配置在压力下仍显著优于基线，但绝对收益被费用侵蚀过半，交易成本敏感性高（段均 21 笔已属低换手，仍然如此）。
5. **52 周高位锚定中性偏差**：段均值 -14.8% vs 基线 -10.9%，但牛市段 +8.5% 保持正、为正段 3/9。它在周期行业分层里曾是正贡献（第五轮），在广域宇宙里无增量——锚定类因子依赖宇宙的内在趋势结构。
6. **分段方式本身的结论**：牛段 vs 熊段的分化比「训练 vs 样本外」更稳定地解释配置差异（所有实验在牛段最好、熊段最差，无一例外）。按状态分段的验证设计应取代等长年份切分成为默认方法；「regime × 宇宙 × 样本」三维联合敏感的判断在分段设计下依然成立（盈利奔跑在牛段也亏 -9.8% 即为例证）。

8. **全叠加在 CH-3 口径下首次跨过正期望线**（+0.9%、5/9 为正、熊段 0.0%、最差 -16.9%），费用压力下回落到 -4.7%。绝对动量 120 的熊段 +0.7% 是全部实验里第一个熊段正值。「正期望」在此口径下不再是全否，但其稳健性仍不足（5/9 而非 9/9，且依赖宇宙清洗与低频交易）。
9. **CH-3 剔除本身不是收益增强器**：基线反而更差（-15.5% vs -10.9%，震荡段 -23.7% 大幅恶化）——小票贡献了震荡段的反弹收益。它的价值是**结论卫生**（防止小票噪声污染因子评价），而非直接提升策略收益。

## 三（续7）、研究收口终验（第九轮，终版结论见《系统策略优化研究_总结论_终版》）

三项收口：①周期行业配置（盈利奔跑+熔断5）并入绝对动量 60/90/120 终验；②13 类周期行业留一消融（full 窗）；③复跑第六轮锚点。裁决：绝对动量并入被否决——默认口径三窗一致恶化（+28.3/+19.0/+68.2% → 加 60 日闸门后 -19.3/+7.8/-4.4%，90/120 档同样劣于基准），且是结构性的而非参数问题：周期股行情（2023-24 资源/中特估）恰启动于指数弱势期，闸门系统性关闭最佳入场窗口。**绝对动量的适用边界 = 与指数同向的宇宙；不适用于逆周期宇宙。** CH-3 口径基准极性不稳维持（-31.5%/+96.1%/+41.7%）。留一消融 13/13 为正（最差 +1.8%：工业金属；其次煤炭 +3.4%），但幅度横跨 +1.8%~+171%（剔除化学原料/石油加工反而翻倍）——利润引擎集中于煤炭+工业金属，幅度路径依赖。**周期行业配置最终评定为观察级：方向采信（三窗正+消融全正+费用压力通过），幅度以区间表述、不作收益承诺；生产化需真实用户评审+滚动复验。**

## 四、逐条结论（对照预案）



1. **预案2（市场状态口径/震荡降暴露）：成立，是本轮最重要的正面结论。** 暴露 93%+ 的所有配置在三窗口全部巨亏（全窗 -53% 到 -80%），而把暴露降到 50—80% 的机制（回撤熔断、宽度确认）全部改善。881 环境口径（综合指数 MA20 斜率）作为熔断恢复条件工作正常。「右侧受限于市场环境、震荡/弱市应降低暴露而非硬做」获得量化支持。
2. **预案3（回撤熔断）：强支持。** 20 日高点回撤 >5% 暂停新开仓（881 MA20 斜率恢复）把全窗收益从 -66.3% 拉到 +68.1%、最大回撤从 73% 压到 26%，三窗口方向一致。代价是样本外牛市只赚 +0.6%（暂停踏空）。连止损熔断单独启用也有改善但弱于回撤熔断；两者同时启用时回撤条件主导。**注意：把阈值调到 12% 在训练窗更优（+71%）但样本外转负——阈值维持预案原定 5%，不要用本轮数据调参。**
3. **预案1（震荡期限制同类 1—2 名）：两轮均无法验证为有效。** 100 只样本同日右侧信号中位数约 1 只，限 2 名几乎从不生效；扩池到 500 只后候选变密，但斜率/ADX 震荡期限 2 仍与基线几乎相同，无条件限仓 2 反而显著更差（训练 -76.0% vs 基线 -62.5%）——候选密集时按 MACD 增量取前 2 名等于只买最伸长的标的，是逆向选择。此条仅在「叠加宽度/熔断等环境过滤之后仍剩大量候选」的场景才可能有意义，本轮数据不支持直接采纳。
4. **预案1（大盘/板块宽度确认）：支持，最稳健的单因素。** 以「881 行业上涨占比 <60% 不开新仓」三窗口皆正且都跑赢基线 40pp 以上；50%/40% 阈值在样本外更优但训练窗弱，60% 是三窗口一致的选择。宽度因子口径为行业数量占比（90 个 881 行业，分子分母可追溯），不是全市场个股宽度。
5. **预案3（提高止损）：不支持简单收紧。** 止损 6% 在所有窗口都更差（更多止损闭环、更高费用）；8%→10% 变差；12% 在训练/全窗为正但样本外 -41%。止损档位与 20 日强制持有、无分批止盈的简化退出强耦合，非单调。在引擎退出规则未对齐生产（冷却期+分批+移动止损）之前，止损调参没有稳定答案；维持 8%（生产技术止损区间 0.88—0.95 的中值附近）。
6. **预案4（震荡判定因素）：MA20 斜率平、ADX<20、贴近MA20、宽度弱四个因素在本样本上与右侧信号日几乎不重叠**（斜率平判定 164/484 日为震荡，但改变交易的只有极少数），单独作为过滤器无效。它们更可能作为环境状态输入（而非交易限制）在更大候选池上起作用。预案中的「涨停/跌停比转弱」因素本轮未验证：本地涨跌停事件数据自 2025-09-01 起才可用，无法覆盖 2023—2026 实验窗口，需等事件历史回补后单独登记实验。
7. **左侧反转：预案「保持严格」的判断需要修正为「保持形态、放宽深度、并扩大候选池」。** 100 只严格样本上左侧三窗皆正但信号太少（两年 35—46 笔）；扩池到 500 只后严格口径反而转负（训练 -3.8%、样本外 -15.6%），说明严格左侧依赖池内恰好有高质量超卖标的。放开实验显示：**「组合A」（5日跌幅-6%→-4%、RSI≤35→≤40、MA20偏离-8%→-5%，形态条件不动）两窗皆正且大幅优于严格口径（训练 +15.9% / 样本外 +20.8%、胜率 50.8%、回撤降至 15.2%、信号量 +55%）**；组合B（更深放宽）次之；单独放宽跌幅或 RSI 一致变差（提前接飞刀）。放宽必须三条件同步、幅度适度，且以形态质量为前提。
8. **试盘/波段：市况依赖，均不足以单独放大。** 波段恰与预案「先修复止损档位和箱体边界数据，再谈调仓」的谨慎一致；组合模式（右+左+波段分仓）三窗皆负，被右侧/波段子账户拖累，预算竞争机制本身未发现问题。
9. **一档止盈（引擎简化为全退）方向对但不稳定**：训练窗 +49pp（相对基线），样本外 -5pp。生产「分批止盈+移动止损」的完整建模才是正路，单档全退不可发布。

## 五、负期望来源诊断（基线，全窗）

- 306 笔闭环：止损退出 161 笔、平均 **-1.34 万元**；20 日到期退出 145 笔、平均 **+1.04 万元**（胜率仅 70%）。
- 盈亏比 0.77，而 33.7% 的胜率需要 1.94 才能打平 → 结构性负期望，费用（全窗 5.8 万元）进一步放大。
- 根因：六条件是「强势确认」信号，次日开盘买入常买在短动量高点；20 日强制退出截断了「大赚几次」的可能，而 -8% 止损把「小亏多次」足额兑现。这与预案 3 的自我判断（本策略非高胜率体系，靠大赚几次）一致——**引擎的简化退出无法兑现大赚，是当前回测负期望的首要原因，优先级高于任何入场参数微调。**

## 六、建议（整体计划变更方向）

**核心结论（五轮后修订）：机械日频信号没有跨宇宙稳健的正期望——但股性分层找到了一个例外：**周期行业 × 右侧盈利奔跑+熔断5** 三窗皆正、通过费用压力（年化 11.5—15.9% → 压力下 +7.8%）。收益改善的方向由此明确：把系统定位为「在经济含义明确的分层宇宙上运行已验证的信号+风控组合，其余环境用熔断护栏止损」，同时用实盘证据线回答人工判断的原生价值。**

**变更方向（按优先级）：**

0. **采纳（最高优先级）：「周期行业 × 右侧盈利奔跑+熔断5」**——三窗皆正（年化 11.5—15.9%）、费用压力下仍 +7.8% 年化、暴露约一半。采纳前提：周期行业集合边缘消融、30bp 滑点压力复验、真实用户策略评审；行业归属为当前回看近似。
0a. **（第八轮新增）绝对动量闸门升级为护栏候选**：综合指数 60/120 日收益低于阈值时停止新开仓，是全部 8 轮里唯一在两种宇宙口径（默认/CH-3 剔除）、三种状态段（牛熊震荡）下一致改善基线的单因素（段均值 -1.9%/-2.5% vs 基线 -10.9%/-15.5%，最差段改善 39pp，牛市段反而更赚）。它语义上与熔断同族（控制"何时不做"），建议与熔断一起进入生产风控三件套的候选评审；残差动量与行业闸门（默认宇宙）维持否定。
0b. **炒作型宇宙维持「无机械信号」结论**：右侧主升（灾难）、深度超卖左侧（负）、试盘回踩（负但亏损收窄过半）在日频机械形态下全部无法转正；炒作票的参与留给打板/情绪分支（需竞价/封单/连板梯队/分时数据，预案第三阶段）与人工执行，不分配日频机械预算。
1. **系统角色重定位——「人选股、规则交易」**：把已验证的三件套（组合级熔断 5%+连损3、宽度确认、左右隔离）固化为所有交易的风控护栏；入场/退出规则只作为纪律执行器运行在**人工维护的短线池**上，不再对广域宇宙做机械扫描。系统的价值主张从「产生收益」改为「防止 -43% 这类结果、把人工判断的执行固定下来」。
2. **实盘证据线优先（近期最高性价比）**：当前实盘只有 7 笔闭环、信号归因为空，无法判定「人工+六条件」在其原生环境（短线池+盘中确认+人工执行）是否有正期望。先做实每日真实结算、信号归因与退出原因记录，积累 30+ 笔归因明确的实盘闭环再决策：有正期望 → 投资盘中执行模型（竞价/分钟线）把人工模式放大；无 → 正式降级右侧，预算集中到人工最有把握的模式。机械回测不能替代这个判断。
3. **机械研究验收标准升级（防止再次追逐样本特异性）**：任何新信号/参数进入采纳讨论前，必须通过「训练/样本外分离 × 费用压力（滑点加倍） × （对统计筛选类）多随机样本」的稳健性验收；实验脚本已具备一键复现能力，把该流程固化为研究规范。本轮 500→1000 池的翻车与振幅过滤的失败都是这个标准缺失的直接代价。同时明确：经济含义明确的分层（行业/股性）不属于「事后统计筛选」，是合法的宇宙定义维度——本轮股性分层就是按这个标准找到的正期望。
4. **数据基建按需排期**：指数日线 2023 年前失真排查、`market_instrument_status_history` 精确停牌、涨跌停事件历史回补（打板/情绪因子的前置）、公司行为账本。这些提升全部后续研究的证据质量。
5. **收益的现实预期管理**：在验证出跨样本正期望之前，系统化部分的合理预期是「回撤可控、避免灾难性亏损」（熔断已证明）；绝对收益的提升来自人工判断质量与纪律执行的结合，而这两个变量的度量只能靠实盘证据线。

**不做：** 继续在广域宇宙上调参/扩池/换统计过滤器的任何变体（五轮数据一致否定）；把任何单样本正结果写进生产策略正文；把右侧动量用于炒作型标的（五轮中最一致的灾难结论）。

## 八、权威量化研究的借鉴映射（2026-09-13 文献调研）

围绕五轮验证结论检索权威量化研究与知名机构方案，按「结论 → 借鉴点 → 落地动作」映射：

| 权威来源 | 核心结论 | 与本系统证据的对接 | 可落地动作 |
|---|---|---|---|
| 行业动量：Moskowitz & Grinblatt 1999（JF，被引 2700+） | 行业动量策略盈利性强于个股动量，赢家行业的成分股持续跑赢 | 直接印证「周期行业 × 右侧动量」三窗皆正，而广域个股动量灾难 | 右侧开仓加**行业动量闸门**：所属 881 行业 20/60 日动量排名前 K 才允许个股信号执行（数据已具备） |
| 时序动量：Moskowitz, Ooi & Pedersen 2012（JFE，被引 2250+）；AQR 总结 | 各资产自身 12 个月收益为正才持有（TSMOM），与截面动量独立，危机期正收益 | 熔断是二值开关；TSMOM 提供连续化的「绝对动量闸门」 | 行业/指数 12 周（60 日）收益为正作为右侧的绝对动量前置条件 |
| 波动率管理：Moreira & Muir 2017（JF，被引 866+）；批评：Cederburg et al. 2020（JFE） | 高波动期降风险产生 alpha——但样本外仅在部分因子成立 | 我们的 position_fraction 是固定值；熔断是极端开关 | **波动率目标仓位**：单笔预算按 20 日已实现波动率缩放（target σ / realized σ）；必须按本系统验收标准先做样本外验证 |
| 回撤约束仓位：Trade Sizing Techniques for Drawdown and Tail Risk Control（SSRN） | 回撤约束下的 Kelly 型连续缩仓算法 | 熔断 5% 是二值开关（触发/恢复） | 把「熔断二值开关」升级为「回撤越深、新开仓预算越小」的连续函数 |
| 双动量：Antonacci（SSRN） | 绝对动量（自身趋势）对回撤的削减作用远大于相对动量 | 「行业趋势闸门 + 个股信号」= 双动量的行业版 | 与第 1、2 条合并为同一实现 |
| 52 周高位：George & Hwang 2004（JF）；国际证据 Liu et al. 2011 | 接近 52 周高位的锚定效应比过去收益更有预测力 | 直接回应「右侧太滞后」：52 周高位接近/突破是比 MACD 全确认更早的趋势确认 | 右侧候选加「现价/52 周高点 ≥ 阈值」过滤（需在本系统按验收标准验证，文献有反例） |
| A 股异象：Jansen et al. 2021（PBFJ）；Zhang 2024；Wu 2011 | A 股常规动量弱/缺失、短期反转强（散户+涨跌停+T+1 结构性原因）；**残差动量在 A 股仍强** | 完整解释五轮现象：炒作型是反转最强群体（右侧 -85.8%）；周期行业趋势由慢变量驱动所以动量存活 | 测试**残差动量**（剥离行业与市场后的个股相对强度）——恰好是「周期行业内的相对强度」的学术化实现 |
| CH-3：Liu, Stambaugh & Yuan 2019（JFE，被引 1000+） | A 股市值最小 30% 是壳价值污染区（反向规模效应，像上市壳期权）；价值因子应用 E/P 而非 B/M | 我们的 2595 合格宇宙与各分层未做市值下限剔除 | **宇宙卫生检查**：分层与样本剔除市值最小 30%（或按 CH-3 口径剔除后重验既有结论） |

**阶段一执行结果（CH-3 卫生检查，换手代理口径）**：周期行业剔除中位成交额最低 30%（457→330 只）后，结果**窗口间极性不稳**：盈利奔跑+熔断5 训练窗 +28.3%→-31.5%、样本外 +19.0%→+96.1%、全窗 +68.2%→+41.7%；费用压力全窗 +65.7% 反高于基准成本的 +41.7%（滑点改变入场价→路径混沌发散）。**裁定：CH-3 排除不采纳（训练/样本外不一致）；同时原「周期行业」推荐降级——其对宇宙构成与成本假设是混沌敏感的，稳健区间应为全窗 +42%~68%（两种口径）而非单点数字。** 根本教训：该配置的闭环样本（200+ 笔）中少数大额盈利单主导结果，输入的良性变化即可引起输出混沌发散——任何单宇宙、单成本口径的正结果都必须按稳健区间表述。

**分阶段落地试验结果（第六轮实施，2026-09-13）**：四个借鉴方向全部实现为引擎能力（`industry_groups`+`industry_momentum` 行业闸门、`near_52w_high_min` 52周高位、`vol_target_sigma` 波动率目标仓位、`drawdown_scale_max` 回撤连续缩仓；均已通过引擎单测）并在周期行业宇宙（CH-3 剔除口径 330 只 / 原始口径 457 只）×训练/样本外/全窗完成消融：

| 配置（周期行业宇宙） | 训练窗 | 样本外 | 全窗 | vs 基线一致性 |

**结论：**

1. **「全叠加」配置（阶段2+3+4 组合）在两个宇宙定义、三个窗口上全部大幅优于基线（+46~66pp），把右侧从灾难压到持平微利、回撤 12—22%**——借用方向整体成立。
2. 单因素层面：**波动率目标**与**回撤连续缩仓**在 CH-3 口径下三窗一致改善基线（+15~33pp / +13~42pp），是有效的风控粒度细化；行业闸门 20 日口径与 52 周高位单独使用不稳定（样本敏感），只在组合中发挥作用。
3. **绝对收益仍然温和（每窗 0—14%）**——全叠加的本质是「在周期行业里只做行业动量前 10、贴近 52 周高位、波动可控、回撤不深的少数信号」，代价是信号频率大幅下降（71—159 笔）。年化口径下这是「低暴露、低回撤、微正收益」的风控型配置，不是高收益引擎。
4. **脆弱性提示**：CH-3 口径下训练窗 +0.5% 与原始口径 -3.4% 表明叠加配置也只是「勉强转正」；盈利奔跑+熔断5 单配置在 52 周高位过滤后出现 +110.3% 的样本外爆点（回撤 15.2%）但训练窗为负——单点爆利不可作为依据。任何采纳都需真实用户策略评审与实盘小额验证。

**执行顺序建议**：先做零成本的宇宙卫生（CH-3 剔除最小 30% 重验周期行业结论）→ 行业动量闸门 + 绝对动量闸门（数据现成）→ 52 周高位过滤（回应「滞后」）→ 波动率目标仓位与回撤连续缩仓（需样本外验证）。每项都走第五轮固化的稳健性验收流程。
