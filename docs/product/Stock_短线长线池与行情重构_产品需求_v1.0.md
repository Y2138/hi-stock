## 一、产品结论

系统不再存在独立的“自选”业务概念。用户关注和研究的股票均以短线池或长线池角色存在；未完成评估的标的不入池，也不建立另一套待评估或自选清单。

页面提供“短线池”和“长线池”两个一级入口。标的档案继续作为中性市场主数据独立维护，策略角色和研究属性继续保存在带有效期的标的池关系中。这样既满足页面上的统一认知，也保留角色演进历史和同一标的只能有一个当前角色的约束。

## 二、对象边界

| 对象 | 定义 | 主要属性 |
|------|------|----------|
| 标的档案 | 数据源可识别的股票、ETF、指数、板块等中性事实 | 代码、名称、类型、交易所、行情能力、生命周期 |
| 标的池角色 | 系统对股票当前研究定位 | 短线/波段/长线/观察、分级、评分、股性、阶段、标签、评估摘要、有效期 |
| 板块 | 同花顺行业、概念、区域、特色板块 | 标准代码、类型、成分、来源、同步时间、行情 |
| 持仓 | 真实组合事实 | 数量、成本、事件流、归因；不决定标的池角色 |

技术实现继续采用 `market_instrument` 与 `pool_membership` 分表：标的档案是一对一主数据，策略角色是带有效期的一对多历史。板块归属为多对多关系，不写入单一文本字段。

## 三、信息架构

### 3.1 一级导航

- 仪表盘
- 持仓
- 短线池
- 长线池
- 任务中心
- 当前策略
- 回测
- 数据与备份
- 设置

“自选”“标的池兼容”和“行情”不再作为一级菜单。行情详情仍保留路由，可从短线池、长线池、持仓、板块、全局搜索和 Agent 回答下钻。

### 3.2 标的池页面

短线池和长线池使用同一页面能力、不同池过滤。页面包含：

1. 固定“近期关注”视图；
2. 用户已排序的常用板块；
3. 其他相关板块的搜索与选择；
4. 当前板块摘要；
5. 当前板块内属于该池的标的列表；
6. 未匹配板块的数据缺口提示。

每个标的至少展示：名称、代码、最新价格、涨跌、行情时间、角色、分级、研究评分、股性、阶段、标签、同花顺官方所属行业和数据状态。

## 四、板块规则

- 同步并维护同花顺行业、概念、区域、特色四类官方目录；标的池所属关系只同步并使用官方行业成分。
- 一个股票可以属于多个官方行业；页面分组不复制标的池记录，ETF 不强制行业归属。
- Agent 入池时只需确认股票至少存在一个当前有效的同花顺官方行业关系，不能自行指定所属行业。
- 库中没有官方行业时，Agent 应先检查目录和成分同步缺口，不能直接创建同名行业或写入本地板块标签。
- 行业顺序是每个池的展示偏好，由 Agent 根据用户指令维护；不改写官方目录顺序。
- 官方行业关系缺失或失效时，标的池角色不删除，页面进入“行业待同步”状态。

## 五、近期关注

“近期关注”是标的池上的可解释状态，不是另一份清单。每条状态包含关注原因、开始时间、结束时间和来源。

- 用户可在对话中要求 Agent 置入或移出近期关注；
- 计划或任务可以提出关注建议，但不能绕过领域写入自动生效；
- 到期后不再出现在近期关注视图，历史角色不受影响；
- 页面显示关注原因和有效期，避免把它误解为永久评分。

## 六、行情与板块下钻

### 6.1 行情入口

行情是标的和板块详情的一部分，不是独立工作模块。全局搜索选择标的后直接打开详情；短线池、长线池和持仓行点击也进入相同详情。

### 6.2 展示范围

- 股票、ETF、指数和板块日 K；
- 数据源已支持时展示 30 分钟线；
- 均线和经过可信计算门禁的 MACD；
- 个股与所属官方行业的行情强弱对比；
- 行情时间、抓取时间、来源、新鲜度和数据缺口。

### 6.3 对比规则

- 只支持主标的与所属官方行业对比，不提供任意两只股票对比；
- 同时对比的行业数量保持受控，默认一个，最多三个；
- 所有序列以前收盘为 0% 归一化；
- 停牌、断流或未采样区间留空，不补零、不前向填充。

### 6.4 临时辅助线

- 首期只提供趋势直线；
- 辅助线只存在于当前页面内存，刷新、切换标的或离开页面后清除；
- 不写数据库、不进入备份、不向 Agent 暴露；
- 页面明确标注“临时辅助线，不构成策略关键位”；
- 删除原水平线、文字标注、跨会话恢复和版本冲突处理。

## 七、迁移与数据处理

1. 以当前有效 `pool_membership` 作为短线池和长线池唯一清单。
2. 迁移前核对旧自选条目是否都已有当前策略角色。
3. 没有策略角色的旧自选不得自动入池；列入迁移报告并等待 Agent 完整评估。
4. 对账完成后删除自选页面、路由、领域工具、运行时查询和数据库当前表。
5. 历史迁移文件不改写；完整私有备份保留迁移前事实。
6. 已持久化图表标注在确认不再需要后删除当前表和 API，不迁入其他业务事实。

## 八、验收标准

1. 一级导航只有短线池和长线池，不再出现自选、兼容标的池或独立行情。
2. 全局搜索、持仓、两个池和板块都能下钻同一行情详情。
3. 每个当前股票池成员拥有角色、评分、阶段、股性和至少一个同花顺官方有效行业；缺失项明确显示并阻止新入池，ETF 行业可为空。
4. 同一标的不存在两个当前池角色；角色切换保留历史且原子生效。
5. 板块页先显示板块行情、成分数量和同步状态，再显示对应池内标的。
6. 个股与板块对比按前收归一，缺口不连接。
7. 页面只提供趋势直线，刷新后消失；数据库和 API 不再存在图表标注写入能力。
8. 旧自选当前表、服务、Agent 工具和前端代码无生产引用。
