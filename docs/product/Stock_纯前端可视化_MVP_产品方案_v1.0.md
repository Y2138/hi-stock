## 一、决策状态

### 1.1 真实用户已确认

1. 产品只用于查看仓库已有事实数据，不提供写入或交易闭环。
2. 不做运行时 Server、数据库、实时行情、仓库外数据、付费数据、外部凭据、计划生成或 AI 建议。
3. 实现路径采用“构建时预处理 + 单文件静态前端”。建议技术基线为 Vite、TypeScript、ECharts；最终产物应能通过 `file://` 打开，不依赖本地 HTTP 服务、CDN 或网络请求。
4. 当前持仓同时展示源文件记录的累计盈亏金额和收益率；账户历史只展示 13 个离散总资产金额快照，不计算或展示历史组合收益率。
5. 首版只覆盖当前持仓，接受单只当前持仓价格表现与上证归一化比较，不要求持仓组合收益与上证比较。
6. 前端不进行二次复权，源文件复权口径无法核实时同屏标“未知”；使用当前 15 板块映射并将 CPO、航空航天标为 ETF 代理；首版不考虑移动端。

第 1 至 3 项来自 YZZ-25 中真实用户对路径 A 的明确选择和本议题的启动范围；第 4 至 6 项来自真实用户在 YZZ-20 于 2026-07-30 的逐项确认。以上均为已确认范围，不再作为待确认默认值。

### 1.2 已核实的数据边界

- 行情 CSV 可支持个股/ETF 日 K、15 个板块日 K，以及单标的价格相对上证指数的归一化比较。
- 当前 74 个行情 CSV 均截至 2026-07-29；多数覆盖 180 个交易日，个别覆盖 61、123、184、285 或 380 个交易日。页面必须按单标的实际范围展示，不能承诺统一历史长度。
- `当前持仓.md` 在 2026-07-29 记录 8 只当前持仓，可作为当前快照使用。（2026-08-16 备注：现行持仓已为 5 只，此处为 2026-07-29 验收口径，验收夹具不变。）
- `支撑/归档/持仓流水/2026年07月.md` 在 2026-07-10 至 2026-07-29 之间只有 13 个不同日期的账户总资产记录；2026-07-24 缺少快照，2026-07-15 有重复标题，多数金额带约数标记。它不能可靠重建逐日组合净值或组合收益。
- CSV 没有逐行记录复权方式、抓取时间、文件版本或可靠品种类型；`volume` 的股、份或指数口径也没有完整元数据。

### 1.3 当前评审状态

YZZ-20 对提交 `cb25789` 的结论为“不通过，暂不授权进入开发”。本修订关闭其产品文档阻断并等待用户代表复审；修订完成不等于复审通过，也不授权设计或开发启动。当前没有阻塞本方案范围定义的真实用户待决项；后续扩大范围必须重新评审。

## 二、用户问题与场景

目标用户是有一定交易经验、时间有限、重视数据可信度的 A 股个人投资者。主要场景是盘后在电脑上快速复盘，而不是获取买卖建议。

| 场景 | 用户要回答的问题 | MVP 输出 |
|------|------------------|----------|
| 打开页面 | 数据截至哪天，哪些数据完整，当前账户和持仓是什么状态 | 全局数据状态、当前持仓快照、账户总资产离散快照 |
| 查看持仓走势 | 某只当前持仓近期跑赢还是跑输上证，差异从何时开始 | 同一共同交易日起归一为 100 的双线比较 |
| 核对个股异动 | 异动处于怎样的价格、成交量和均线背景 | 个股/ETF 日 K、成交量、MA5/10/20/60 |
| 核对板块共性 | 某个板块或代理品种自身处于怎样的日线位置 | 15 板块日 K，代理与分类口径明确标注 |
| 核验结论 | 图表来自哪个文件，截止时间、单位、缺口和口径是什么 | 每图来源摘要和一层可达的数据说明 |

主要任务路径：

1. 用户打开页面，先确认全局行情截止日、账户截止日、构建时间和异常数量。
2. 用户查看当前持仓、逐只单日价格变化和账户离散快照，先定位当日变化最大的持仓；账户历史只表达已记录日期的金额，不表达连续收益。
3. 用户选择一只当前持仓，比较其价格表现与上证指数。
4. 用户下钻该标的日 K；需要核对共性时切换到板块日 K。
5. 用户在任一视图查看来源、单位、复权状态和缺失日期。

## 三、产品目标与非目标

### 3.1 目标

- 用户首次打开后 30 秒内能说出数据截止日、当前总资产和持仓数量，并识别是否存在缺失或未知口径。
- 用户能在一个页面内完成当前持仓查看、单标的相对上证比较、个股/ETF K 线和板块 K 线核对。
- 用户能在总览按单日价格涨跌幅绝对值识别变化最大的当前持仓，并直接进入该标的对比或 K 线。
- 所有图表都可追溯到仓库事实文件；截止时间、单位、复权状态和异常不被正常样式掩盖。
- 缺失、重复、口径变化或不可比较时保留事实边界，不插值、不前值填充、不补零、不伪造历史。
- 产物离线、只读、可复建，不把构建产物变成第二事实源。

### 3.2 非目标

- 完整组合净值、组合收益率、组合与上证收益对比、绩效归因、时间加权收益、资金加权收益、回撤曲线。
- Server、数据库、API 服务、本地常驻进程、用户账号、云同步、跨设备同步或远程访问。
- 实时或盘中行情、自动刷新、行情拉取、数据订阅、付费数据和仓库外数据源。
- 成交录入、事实源写入、计划生成或发布、标的池维护、执行位计算、风险告警、下单或券商连接。
- 选股、预测、资讯、AI 建议、买卖建议、综合推荐分或把计划情景表达为确定事实。
- 已清仓标的和历史持仓的完整分析；移动端适配或移动端专属工作流；大而全的技术指标库。

## 五、页面信息架构与桌面布局

### 5.1 单页结构

单文件产物使用一个页面和前端内切换，不依赖路由服务。

| 区域 | 首要信息 | 关键交互 |
|------|----------|----------|
| 固定页头 | 产品名、盘后只读标识、行情/账户截止日、构建时间、全局状态 | 打开数据说明；状态异常时直接定位受影响视图 |
| 总览 | 当前资金摘要、持仓表、逐只单日价格变化、账户总资产离散快照 | 默认按单日涨跌幅绝对值排序；分别直达标的对比或 K 线 |
| 标的对比 | 当前持仓与上证归一化双线及区间摘要 | 选择标的、切换范围、悬停或键盘聚焦、缩放、复位 |
| K 线 | 当前持仓个股/ETF 日 K 与成交量 | 选择标的、切换 MA、缩放、十字线、复位 |
| 板块 | 15 板块日 K 与映射说明 | 选择板块、切换 MA、缩放、十字线、复位 |
| 数据说明 | 数据集清单、来源、哈希、范围、单位、复权、缺失和构建结果 | 按状态筛选；展开单个数据集详情 |

页面默认进入“总览”。切换视图后保留已选标的和时间范围；个股对比与个股 K 线共享当前标的，但不强迫板块映射联动，因为当前事实源没有可靠的逐标的板块归属。

### 5.2 信息层级

1. 截止时间和完整性先于金额与涨跌。
2. 当前账户事实先于历史趋势。
3. 比较结论先于技术细节，数据异常位于受影响结论同一层级。
4. 来源路径、哈希和行数默认收起，但最多一次操作可见。

### 5.3 桌面布局范围

- 首版仅验收桌面浏览器，主要设计宽度为 1280 至 1440 像素，最小验收视口为 1024×768。
- 1024 像素宽度下允许总览卡片和图表上下排列，但持仓关键字段、截止日、异常状态、标的名和单位不得隐藏；页面不得横向溢出，文本不得与图表或控件重叠。
- 小于 1024 像素的视口不属于 MVP 支持和验收范围，产品不得宣传为移动端可用；本期不设计移动端导航、点按提示、手势缩放或信息压缩规则。
- 桌面端所有交互必须可由鼠标和键盘完成，颜色不得作为涨跌、异常或代理类型的唯一识别方式。

## 六、P0 视图契约

### 6.1 当前持仓快照

| 项目 | 定义 |
|------|------|
| 用户问题 | 当前账户有多少资金、多少现金、持有哪些标的，各自累计盈亏如何，以及最近一个有效交易日哪些持仓价格变化最大 |
| 输入 | `当前持仓.md` 顶部资金摘要和“实时持仓总览”主行；忽略“股性”等从属说明行；每只当前持仓对应行情 CSV 的 `time`、`close` |
| 核心字段 | 总资金、证券市值、现金、浮动盈亏、当日盈亏、更新日期；标的名、代码、数量、数量单位、成本口径、收盘价、市值、累计盈亏金额、收益率、角色、占比、实盘例外；最近有效交易日、单日价格变化额、单日价格涨跌幅、单日变化状态 |
| 单日价格变化 | 对每只持仓取其行情 CSV 最近两个有效收盘价，按 `最新收盘价 - 前一有效收盘价` 和 `最新收盘价 / 前一有效收盘价 - 1` 计算；明确显示最新收盘价对应交易日。该值是标的价格变化，不是账户当日盈亏或组合贡献 |
| 口径 | 原样保留“约数”“券商显示”“策略参考”等口径；同一标的多成本口径不得合并成一个精确成本 |
| 默认范围 | 最新一份当前持仓快照；当前夹具为 2026-07-29 的 8 只持仓 |
| 对比基准 | 无 |
| 交互 | 默认按单日价格涨跌幅绝对值降序，正负号和涨跌文字保留；可切换按涨幅、跌幅、市值、累计盈亏或角色排序。每行提供“进入对比”和“进入 K 线”两个明确动作，进入后保留所选标的 |
| 截止与来源 | 区域标题显示 `当前持仓.md` 的更新日期；详情显示源路径和构建时文件哈希 |
| 空/缺失/错误 | 单只持仓行情文件缺失时按第 8.1 节使构建失败；文件存在但少于两个有效收盘价或最新日期落后时，该行单日变化显示“不可用”或实际交易日，总览标 `partial_available` 并列出原因，其他持仓继续排序。顶部摘要可解析但个别持仓记录无效时同样标 `partial_available`；资金与持仓汇总不一致时两者都展示并标 `SOURCE_CONFLICT`，不自行修正 |

当前快照不展示止盈止损、操作指令或计划动作，避免把只读趋势页扩展成交易执行页。

### 6.2 已记录账户总资产快照

| 项目 | 定义 |
|------|------|
| 用户问题 | 已记录日期上的账户总资产金额如何变化，哪些交易日没有账户快照 |
| 输入 | `支撑/归档/持仓流水/2026年07月.md` 的日期段和明确记录的总资金、证券市值、现金；交易日日历取 `支撑/data/上证指数_000001.csv` |
| 核心字段 | 日期、总资产、证券市值、现金、原始金额文本、精度状态、记录来源 |
| 口径 | 金额统一换算为人民币元用于坐标，但保留原始文本；含 `~`、`约` 或 `K` 的值标为“约数”。不计算收益率、盈亏、回撤或超额收益 |
| 默认范围 | 全部有效记录；当前为 2026-07-10 至 2026-07-29 的 13 个离散点 |
| 对比基准 | 无 |
| 图形 | 只显示点，不用连续折线或面积填充；缺少快照的交易日在横轴保留缺口标记 |
| 交互 | 鼠标悬停或键盘聚焦显示日期、金额、精度和可用的证券/现金拆分；可切换“总资产/证券市值/现金”，默认只开总资产 |
| 截止与来源 | 图名固定为“账户总资产离散快照”，标题显示最后记录日；标题、图例、导航、说明和无障碍名称均不得使用“收益曲线”“组合净值”或“组合收益”命名这些记录 |
| 空/缺失/错误 | 当前夹具需标出 2026-07-24 缺失；重复日期仅在唯一有效记录可判定时去重并产生警告，多个有效值冲突时该日不绘制并标来源冲突 |

### 6.3 单标的与上证归一化比较

| 项目 | 定义 |
|------|------|
| 用户问题 | 所选当前持仓在同一可比区间内相对上证是更强还是更弱 |
| 输入 | 所选标的 `支撑/data/{名称}_{代码}.csv` 与 `支撑/data/上证指数_000001.csv` 的 `time`、`close` |
| 核心字段 | 日期、标的收盘价、上证收盘点位、双方归一化值、双方区间涨跌、差值、共同起始日 |
| 可比计算集 | 先限制在所选日期范围，再取双方有效收盘价日期的交集；共同起始日、共同结束日、双方区间涨跌和价格表现差只使用该交集，少于 2 个日期时不计算 |
| 展示日期轴 | 横轴使用双方有效日期的并集并排序，保留只有一方有值的日期；每条序列在自身缺失日期写入 `null`，禁止开启跨空值连线。单边日期上的已有值只提供价格上下文，提示为“不参与当日比较” |
| 归一化 | 首个共同交易日为 `d0`，双方以各自在 `d0` 的收盘价为 100；每条序列可在自己的有效日期按 `close(t) / close(d0) × 100` 展示，但共同区间摘要和差值只读取可比计算集 |
| 区间差值 | 在可比计算集最后一个共同日期，以 `标的区间涨跌率 - 上证区间涨跌率` 计算并标为“价格表现差”，不称为组合超额收益或组合贡献 |
| 默认范围 | 最近 3 个月；快捷范围为 1月、3月、6月、全部。数据不足时展示实际覆盖，不外推 |
| 对比基准 | 上证价格指数 `000001.SH`，不是全收益指数 |
| 交互 | 选择当前持仓、范围切换、基准显隐、十字线或键盘同步提示、拖拽缩放、复位；切换标的保留时间范围 |
| 截止与来源 | 同时显示两条序列各自截止日、共同起始日和共同结束日；来源详情列出两个文件 |
| 空/缺失/错误 | 共同有效日期少于 2 个时进入 `not_comparable`；任一序列缺失处必须断线，不插值、前值填充或补零；列出仅一方缺失的日期数量和区间，其他独立视图仍可用 |

这张图只比较单标的价格表现与上证，禁止命名为“持仓组合 vs 上证”或“组合收益”。

### 6.4 个股/ETF 日 K

| 项目 | 定义 |
|------|------|
| 用户问题 | 所选当前持仓的近期价格、成交量和均线结构是什么 |
| 输入 | 当前持仓对应行情 CSV 的 `time`、`open`、`high`、`low`、`close`、可空 `volume`、`MA5`、`MA10`、`MA20`、`MA60`、`currency` |
| 核心字段 | 日期、OHLC、单日涨跌率、成交量、MA5/10/20/60、价格单位、成交量口径、复权状态 |

### 7.1 单文件生成物、版本控制与分发

| 项目 | 规则 |

### 7.4 证据类型

MVP 区分以下内容类型，避免把展示计算、人工判断或计划情景混写为行情事实：

| 类型 | 本期示例 | 展示规则 |
|------|----------|----------|
| 行情事实 | OHLC、成交量、上证点位 | 标明交易日、单位、仓库来源和上游元数据状态 |

## 八、构建门禁、状态与恢复

### 8.1 构建门禁

发布构建的必需输入包括 `当前持仓.md`、构建配置指定的账户流水文件、上证指数行情 CSV、从当前持仓解析出的每只标的行情 CSV，以及当前 15 板块映射对应的全部行情 CSV。任一必需文件不存在、不可读、无法映射，或核心文件无法解析出资金摘要、当前持仓、账户日期与总资产等必需结构时，构建必须非零退出、列出相对路径和受影响视图，不得生成新的 `project/dist/stock-viewer/index.html`，也不得覆盖上一次产物。浏览器运行时不得跨目录补读或联网补数。

文件存在但个别记录、可空字段或独立图表无效时，可按下述状态生成 `partial_available` 页面；这不降低“必需文件必须存在”的构建门禁。

### 8.2 单一主状态枚举

每个数据集和视图只能有一个 `status` 主状态，其他问题放入可并存的 `issues`。全局状态按 `unavailable`、`render_error`、`not_comparable`、`partial_available`、`delayed`、`available` 的顺序取最严重状态；初始化期间临时使用 `loading`。

| `status` | 触发条件 | 页面行为 | 恢复条件 |
|----------|----------|----------|----------|
| `loading` | 单文件已打开，正在解析内嵌数据或初始化视图 | 保留稳定占位，不显示 0 或上次值 | 初始化成功后自动进入其他状态；失败进入 `render_error` |
| `available` | 必填数据和校验通过，且没有更高优先级问题 | 正常展示实际截止日 | 无需恢复 |
| `delayed` | 提供了目标交易日且实际截止日更早，数据本身仍有效 | 允许查看旧数据，同屏显示实际日、目标日和影响 | 更新事实输入并重新构建；页面不得自行改成“最新” |
| `partial_available` | 仍有独立有效内容，但存在缺日、无效记录、可空成交量缺失或其他局部问题 | 只展示有效部分，列出问题数量和范围 | 修复输入并重新构建；未修复前不得插值、前值填充或补零 |
| `not_comparable` | 两条比较序列共同有效日期少于 2 个 | 禁用比较摘要，显示双方范围、交集数量和原因 | 选择有足够交集的范围/标的，或修复输入后重建 |
| `unavailable` | 文件存在但受影响数据集没有有效记录，或映射/来源冲突使其不能展示 | 受影响视图显示原因；其他独立有效视图继续工作 | 修复冲突或有效记录并重新构建 |
| `render_error` | 内嵌数据已通过校验，但单个图表初始化或渲染失败 | 原位显示错误摘要、“重试图表”和“重新加载页面”；其他视图保持可用 | 先重试该图表，失败后可重载页面；重复失败时保留错误证据供实现排查，不伪装为数据问题 |

### 8.3 问题代码与展示

`issues` 至少覆盖 `EMPTY_DATA`、`INVALID_ROW`、`SOURCE_CONFLICT`、`STALE_DATA`、`MISSING_DATE`、`VOLUME_MISSING`、`METADATA_UNKNOWN`、`APPROXIMATE_VALUE`、`MAPPING_CHANGED` 和 `RENDER_INIT_FAILED`。其中：

- `METADATA_UNKNOWN` 和 `APPROXIMATE_VALUE` 是可见警告，不单独降低主状态；未知上游来源、复权或成交量单位必须在受影响数字或图表同屏显示，约数必须保留原始 `~`、`约` 或 `K` 标记。
- `MISSING_DATE` 必须使比较图在单边缺日处写入 `null` 并断线；不得因为另一方有值而连接缺口。
- `SOURCE_CONFLICT` 不得自动挑选一个值覆盖另一个；受影响日期或数据集进入 `unavailable`，其余独立内容继续展示。
- 13→15 板块映射变化以 `MAPPING_CHANGED` 展示生效日，不得静默连成同一聚合历史。

## 十、已确认范围决策

| 编号 | 真实用户决定 | MVP 落地 | 后续扩大范围的前置条件 |
|------|--------------|----------|--------------------------|

| D2 | 只看当前持仓 | 标的选择器只含 `当前持仓.md` 的当前持仓；已清仓和历史持仓不进入 P0 | 增加可靠的持仓生效区间、名称映射和历史交易事实 |
| D3 | 前端不进行二次复权 | 按源文件展示；源复权元数据缺失时同屏标“复权口径：未知” | 先获得可验证的上游复权元数据；不得仅凭用户选择推断源口径 |
| D4 | 使用当前板块映射 | 使用当前 15 板块受控映射；CPO、航空航天显式标 ETF 代理；不自动把个股映射到板块 | 新分类或多板块归属需新增版本化映射事实源和生效规则 |
| D5 | 首版不考虑移动端 | 只验收 1024×768 及以上桌面视口，不包含移动端布局、点按或手势规则 | 移动端任务、信息压缩、性能和本地文件交付方式单独设计评审 |
| D6 | 首版接受单只当前持仓与上证比较 | 只做单标的价格表现归一化比较，不做持仓组合收益与上证比较 | 补齐可靠组合收益事实并单独评审基准、现金流和收益计算口径 |

以上决定由真实用户在 YZZ-20 于 2026-07-30 确认，不是保守默认。后续选择如扩大数据、视图、设备或收益计算范围，必须新增评审，不能反向改写本期决定。

## 十一、验收标准

### 11.1 交付与边界

1. 构建后唯一生成物位于 `project/dist/stock-viewer/index.html`；断网并通过 `file://` 打开时，所有 P0 视图可用，页面不发出网络请求。
2. 页面及构建过程不写入 `当前持仓.md`、持仓流水、行情 CSV、计划、策略或标的池；源文件变化后只能重新构建。
3. 页面不存在 Server、数据库、登录、交易、写入、计划生成、AI 建议、实时行情或外部数据入口。
4. 产物和错误信息不包含 Token、外部凭据或绝对本机用户目录。
5. 构建后 `git status --short -- project/dist/` 没有可提交产物；构建成功提示和页面数据说明区都明确提示文件内含当前持仓与账户金额、默认不得提交或分享，页面没有下载、分享或上传入口。
6. 在隔离夹具中删除任一必需文件后构建非零退出，错误列出缺失的仓库相对路径和受影响视图，不生成新 `index.html`，也不覆盖预先存在的旧产物。

### 11.2 正常数据

7. 使用 2026-07-29 夹具构建时，总览显示 8 只当前持仓，资金摘要、累计盈亏金额、收益率和每行其他主要字段与 `当前持仓.md` 一致；多成本口径与实盘例外没有被合并或丢失。
8. 每只当前持仓显示其最近有效交易日、单日价格变化额和涨跌幅，按涨跌幅绝对值降序的结果可由最近两个有效收盘价复算；每行可分别直达已选中该标的的对比视图和 K 线视图，任何文案不称其为组合贡献。
9. 将一只持仓行情裁剪为少于两个有效收盘价后，该行显示“单日变化不可用”，总览为 `partial_available`，其余持仓仍可排序和下钻。
10. 账户图显示 2026-07-10 至 2026-07-29 的 13 个不同日期金额点，图名固定为“账户总资产离散快照”，不显示历史组合收益率，并标出 2026-07-24 缺失和 2026-07-15 重复标题警告。
11. 单标的对比默认最近 3 个月，首个共同交易日双方都等于 100；任意共同日期的归一化值和价格表现差可由第 6.3 节公式复算一致，摘要计算没有读取单边日期。
12. 当前 7 只持仓与上证在现有数据中可得到 180 个共同交易日，电力 ETF 可得到 61 个；页面按实际覆盖展示，不把较短序列延长。
13. 个股/ETF K 线通过鼠标或键盘可读出日期、OHLC、涨跌率和成交量；MA5、MA20 默认开启，MA10、MA60 可独立开启。
14. 板块选择器恰有当前 15 个板块；CPO 和航空航天始终显示“ETF 代理”，机器人显示 2026-07-28 口径生效说明。

### 11.3 异常与可信度

15. 在比较夹具中分别删除标的独有日期和上证独有日期：展示轴仍含双方日期并按并集排序，缺失一方写入 `null` 且该线断开；提示标“不参与当日比较”，共同区间指标保持不变。
16. 构造单日缺失、连续多日缺失、完全空数据、非法 OHLC、重复日期冲突和两序列共同日期少于 2 个，页面分别进入第八章规定的主状态，不插值、不前值填充、不补零；`status` 不出现枚举外值。
17. 删除某日 `volume` 后，价格 K 线仍展示，该日成交量为空、数据集为 `partial_available` 且同屏显示“成交量未记录”；负数成交量则被报告为无效值，不画成负柱或零。
18. 任一图最多一次操作可看到两组证据：仓库相对路径、哈希、源截止日、覆盖范围和行数，以及上游提供方、获取方式、抓取时间、复权和成交量单位。
19. 移除夹具中的全部上游元数据后，仓库路径与哈希仍正常展示；同一详情及受影响图表分别显示“上游来源：未记录”“获取方式：未记录”“抓取时间：未记录”“复权口径：未知”，且不从文件名或字段推断。
20. 行情截止日、账户截止日或目标交易日不一致时同屏显示实际日期和影响，不使用“实时”“今日最新”等文案。
21. 对原始文本含 `~`、`约` 或 `K` 的账户金额，页面保留原始文本和“约数”标记；坐标换算结果不得显示为无标记的精确金额。
22. 单个数据集存在局部无效记录时，其他独立有效视图仍可用；全局状态显示 `partial_available` 和受影响数量。映射或有效值冲突时不自动二选一。
23. 注入一次图表初始化失败后，仅该图进入 `render_error`，原位显示错误摘要和“重试图表”；解除故障后重试可恢复，其他视图在整个过程中保持可用。
24. 任何账户记录都不被命名为收益曲线、组合净值、组合收益或组合回撤；任何单标的价格变化或价格表现差都不被命名为组合贡献或组合超额收益。

### 11.4 交互与桌面布局

25. 标的对比与个股 K 线共享标的选择；切换视图或标的时保留用户选择的时间范围，复位可回到最近 3 个月。
26. 在 1440×900 和 1024×768 下无横向页面溢出、文字遮挡或控件重叠；两种视口都能读取截止日、异常、标的名、单日变化对应交易日和单位。小于 1024 像素不纳入验收。
27. 所有只靠悬停出现的信息也能通过键盘聚焦获取；颜色不是涨跌、异常或代理类型的唯一识别方式。
28. 用户首次打开后 30 秒内，能够正确回答数据截止日、当前总资产、持仓数量、单日价格变化最大的持仓及其交易日、账户历史是否连续，以及是否存在口径未知。

## 十二、风险、依赖与后续候选

| 风险/依赖 | 当前影响 | 处理原则 |
|-----------|----------|----------|
| Markdown 结构漂移 | 可能解析错资金或持仓 | 构建时严格校验，失败即停止受影响数据集，不在浏览器中猜测 |
| `支撑/data/` 被 Git 忽略 | 新环境可能没有行情文件 | 构建前按 `数据获取规范.md` 初始化；缺文件不得交付空壳产物 |
| 复权、上游来源与单位元数据不足 | K 线解释可能被误读 | 仓库文件证据与上游口径分组；缺失项同屏明示“未记录/未知”，不推断 |
| 账户流水不完整 | 不能计算组合收益与回撤 | 只展示离散金额快照；不以视觉平滑掩盖缺口 |
| 13→15 板块变化 | 历史聚合不可直接比较 | 首版不做聚合；保留生效日和代理类型 |
| 单文件体积与图表性能 | 74 个行情文件全部内嵌可能增加打开耗时 | P0 只嵌入当前持仓、上证和 15 板块所需数据；扩大全标的范围另行评审 |

只有在本期验收通过并获得新的真实用户确认后，才讨论以下候选：历史持仓范围、完整账户收益与回撤、标的到板块的版本化映射、更多基准、移动端专属体验或全标的浏览。它们均不属于当前 MVP。
