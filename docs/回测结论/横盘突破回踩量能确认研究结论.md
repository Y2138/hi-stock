# 横盘突破回踩量能确认研究结论

> 状态：P0历史消融完成，P1前瞻冻结入口已建立；不修改生产策略。
> 冻结日期：2026-09-21。
> 前瞻起始日：2026-09-22。
> 证据资格：`research_only`。

## 一、冻结规则

当前基准保持为：突破前20日箱体宽度不超过20%，收盘突破箱体；2至8个交易日内回踩突破位不破并以阳线重新确认；突破量不低于前20日均量1.2倍，确认后下一可用开盘且缺口不超过3%进入事件收益统计。

本轮只做四个固定消融，不继续网格寻优：

1. 突破强量：突破量/前20日均量不低于1.5；
2. 三段量价确认：突破强量，回踩期均量/突破量不高于0.70，确认量/前5日均量不低于1.10；
3. 波动收缩三段量价：三段量价确认，且突破前10日振幅/20日振幅不高于0.75；
4. 三倍量标签：当前基准中突破量/前5日均量不低于3，只作分层标签。

收益按确认后下一可用开盘计算，默认计双边10bp，并另列30bp压力。相邻15个交易行内同股同规则只保留首次。

## 三、裁定

1. 当前横盘突破回踩规则继续作为P1主要观察基准，不提高生产优先级。
2. 把突破量门槛由1.2倍提高至1.5倍只带来极小均值变化，中位数、胜率和MAE没有同步改善，不形成新策略版本。
3. 强制“突破放量、回踩缩量、确认再放量”的三段量价条件显著减少样本，但周期行业和全市场的典型收益、胜率均下降；确认日重新放量更接近再次加速，而非更安全的确认。
4. 10日相对20日振幅收缩在全市场没有稳定提升，在周期行业前窗为负，不作为硬条件。
5. 三倍量样本没有优于当前基准。三倍量只保留为研究标签，不作为候选资格或加分项。
6. 本轮支持“价格结构优先、突破日适度放量即可”，不支持继续收紧量能门槛。
7. 当前基准20日中位收益仍为负，事件级均值依赖右尾；P1只做前瞻记录，不进入生产信号、仓位或每日计划。

## 四、P1前瞻冻结

前瞻入口固定使用本文件第一章全部规则和代码生成的规则哈希。每日数据落库后可执行：

```bash
npm run research:box-volume:prospective -- --date=YYYY-MM-DD
```

命令只接受2026-09-22及以后、且日线已落库的日期；同一日期快照已存在时拒绝覆盖。输出保存在私有忽略目录 `支撑/tmp/横盘突破回踩量能确认研究/`，不进入Git、不写生产策略或业务表。

P1至少积累60个交易日后再汇总；汇总前不修改阈值、不替换全市场股票范围、不按结果删除失败信号。主要观察当前基准，其他四类仅作固定标签消融。

## 五、证据边界

- 历史研究使用前复权价格；
- 下一可用开盘近似成交，未完整模拟停牌和涨跌停成交限制；
- 周期行业使用当前成分回看；
