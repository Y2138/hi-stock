# 结构入场与退出研究结论

> 状态：历史事件与退出结构研究完成；不接入生产策略。
> 验证日期：2026-09-21。
> 证据资格：`research_only`。

## 一、研究规则

### 低位波动收缩直接突破

同时满足：

1. 过去20日箱体宽度不超过15%；
2. `ATR10 / ATR40 ≤ 0.75`；
3. MA20不低于MA60，MA60近5日不明显下降；
4. 过去60日收益位于-20%至+30%，排除已经大幅加速的标的；
5. 收盘突破过去20日最高价；
6. 突破量为过去20日均量的1.2至2倍；
7. 收盘距离MA20不超过2ATR；
8. 次日开盘缺口不超过3%。

初始风险线取“箱体上沿下方1ATR”和“突破前5日最低价下方1%”中较高者，并受入场价下方2ATR约束；风险距离只接受1%至10%。

### 趋势缩量回踩再启动

同时满足：

1. MA20高于MA60且MA20继续上行，MA60近5日不明显下降；
2. 过去60日收益为正，收盘距离60日最高价不超过15%；
3. 过去10日相对20日高点回撤5%至12%；
4. 回踩接近MA20，期间收盘没有明显破坏MA20；
5. 回踩期5日均量不超过20日均量的70%；
6. 收盘突破过去5日最高价并收阳；
7. 触发日成交量高于前一日或不低于5日均量；
8. 次日开盘缺口不超过3%。

初始风险线取回踩低点下方1%和入场价下方2ATR中较高者；风险距离只接受1%至10%。

### 退出结构

| 退出 | 规则 |
|---|---|
| 结构止损40日 | 初始风险线止损，最长持有40日 |
| 1R保本40日 | 最高价达到1R后风险线抬到入场价，最长40日 |
| 2R减半3ATR | 达到2R减半，剩余仓位使用最高收盘减3ATR，最长60日 |
| 20日低点60日 | 初始止损；持有10日后收盘跌破此前20日最低价退出，最长60日 |
| 时间止损3ATR | 10日未达到0.5R退出；达到2R后使用最高收盘减3ATR，最长60日 |

日线内同日同时触发止损和盈利条件时按止损先发生；收益计双边10bp，并另做30bp压力。

## 四、退出结构裁定

1. **2R减半加3ATR不成立。** 两类信号中都明显削弱右尾，利润因子和平均R低于简单持有结构。
2. **10日未达0.5R退出没有改善。** 时间退出减少持有期，但同步削弱平均R和利润因子。
3. **1R保本只改善持仓体验，不改善期望。** 它减少部分完整亏损，在周期行业趋势回踩中把中位R改善到接近0，但显著压低平均R和2R、3R到达率。
4. **低位直接突破最适合20日低点退出。** 全市场平均R和利润因子最高，但中位交易仍为完整止损，且年度表现高度不均衡。
5. **趋势缩量回踩再启动不需要复杂退出。** 全市场中结构止损40日与20日低点60日接近；周期行业中20日低点退出更好，但不足以证明行业专属生产规则。
6. 趋势类策略的收益来自少数大赢家，不能用高胜率作为优化目标；同时，当前两类信号的初始止损率仍过高。

## 五、最终裁定

### 低位波动收缩直接突破

- 保留为前瞻研究候选；
- 固定使用20日低点60日作为主退出，结构止损40日作为对照；
- 不用于周期行业专项策略；
- 必须经过新增行情验证其2024至2025年的优势是否延续；
- 当前不接入生产，因为中位R约-1、年度状态依赖明显。

### 趋势缩量回踩再启动

- 保留为前瞻研究候选；
- 全市场主退出使用结构止损40日，20日低点60日作为对照；
- 周期行业结果可单独记录，但不能使用当前成分回看结果宣称行业优势；
- 不采用2R减半或10日时间止损；
- 当前不接入生产，因为2022、2023和2026年均未形成稳定正期望。

### 后续验证

只冻结以下四组，不继续调整入场阈值或退出参数：

1. 低位波动收缩直接突破＋20日低点60日；
2. 低位波动收缩直接突破＋结构止损40日；
3. 趋势缩量回踩再启动＋结构止损40日；
4. 趋势缩量回踩再启动＋20日低点60日。

新增行情前瞻验证至少持续60个交易日，并分别报告信号数、初始止损率、平均R、中位R、利润因子、1R/2R/3R到达率和年度/市场状态分布。
