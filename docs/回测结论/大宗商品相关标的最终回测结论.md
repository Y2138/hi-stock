# 大宗商品相关标的最终回测结论

> 结论日期：2026-09-16
> 证据等级：研究结论。铜保留已验证的研究级定时评估；碳酸锂保留短样本前向观察任务；其余商品不进入当前策略或定时研究任务。

## 一、最终裁定

大宗商品股票不能共用一套库存、仓单、技术入场和退出规则。经过铜、铝、锌、碳酸锂和动力煤的分品种验证，当前仅保留铜的SHFE库存连续仓位覆盖；其他品种全部排除出当前系统研究信号。

| 商品 | 最终裁定 | 原因 |
|---|---|---|
| 铜 | **保留研究级定时评估** | 库存历史最长、公司商品暴露较直接，前窗和后窗风险改善方向一致 |
| 碳酸锂 | 不进入正式策略；保留周度前向观察 | 官方仓单仅从2023年12月开始，历史不足三年，当前任务只用于积累未来验证证据 |
| 铝 | 排除 | 更换为指定核心标的后，库存连续仓位仍未超过满仓等权基线 |
| 锌 | 排除 | 库存连续仓位未通过，样本公司普遍存在铅、银、锗等多金属暴露 |
| 动力煤 | 排除 | 连续库存代理止于2019年6月，无法覆盖当前煤炭周期 |
| 镍、铅、锡 | 排除 | A股缺少足够的单一商品直接暴露核心矿企，不满足至少三只、优选五只的组合条件 |
| 黄金、白银 | 不纳入本研究 | 驱动因素以实际利率、美元和避险需求为主，不适合强套工业品库存模型 |

因此：

1. 不建设统一大宗商品研究引擎。
2. 不建设统一大宗商品Agent任务。
3. 不继续为铝、锌、煤炭、镍、铅、锡补充数据来修复已经失败的假设。
4. 碳酸锂保留数据同步和每周Agent评估，但结论始终标注短样本、研究级和不可交易。
5. 铜专用同步、确定性信号工具和周度Agent评估保持现状。

## 二、铜：唯一保留的研究方向

### 2.1 数据与窗口

| 项目 | 口径 |
|---|---|
| 股票回测全窗口 | 2016年9月12日至2026年9月11日 |
| 参数选择前窗 | 2016年9月12日至2022年12月30日 |
| 后窗复核 | 2023年1月3日至2026年9月11日 |
| `CU0` | 2014年1月2日至2026年9月15日 |
| SHFE铜总库存 | 2015年1月9日至2026年9月11日，共598周 |
| 核心股票 | 铜陵有色、云南铜业、江西铜业、西部矿业、洛阳钼业 |

### 2.2 固定规则

```text
库存4周变化 = 本周库存 / 四个观测前库存 - 1
库存逆百分位 = 1 - 当前变化在此前已发布历史变化中的经验百分位
研究目标股票仓位 = 50% + 50% × 库存逆百分位
调仓缓冲 = 20个百分点
核心股票 = 五只等权
执行 = 库存可得后的下一A股交易日开盘
```

库存变化只决定研究目标总仓位，不进行个股强弱排名，不使用铜价20日/60日趋势硬门禁。

### 2.3 主要结果

| 窗口 | 满仓核心等权 | 铜库存连续仓位 | 铜库存连续仓位最大回撤 |
|---|---:|---:|---:|
| 前窗总收益 | +60.1% | +100.9% | 48.0% |
| 后窗总收益 | +228.2% | +158.4% | 27.9% |
| 全窗口总收益 | +424.7% | +419.9% | 48.0% |
| 全窗口年化 | +18.8% | +18.7% | — |

全窗口中，库存连续仓位以约77%的平均股票暴露取得接近满仓等权的累计收益，最大回撤由56.4%降至48.0%，年化波动由44.9%降至34.8%。压力场景采用双边30bp滑点和库存信号额外延迟5个交易日，后窗仍保持正收益和较低回撤。

### 2.4 已否决的铜规则

以下规则不进入系统：

- 铜价20日和60日趋势硬门禁；
- 库存下降硬开关；
- 20日个股相对强度排名；
- MA20修复或20日突破入场；
- 统一2ATR/10%初始止损；
- 1.5R、3R分批止盈；
- ATR移动止损；
- 顶部风险收紧止损；
- 止损仓位向其他铜股重新分配。

隔离研究表明，铜加入移动止损后，普通后窗收益和Calmar均低于库存连续仓位基线，再分配还会提高集中度、换手和交易成本。

### 2.5 系统状态

铜保留以下任务：

```text
commodity_copper_inventory_sync
每周五17:10同步SHFE铜库存

copper_inventory_signal_review
每周五17:30解释固定信号
```

Agent只读取服务端确定性计算结果，不自行改公式、参数或股票名单，不写真实持仓，不自动交易。

## 三、碳酸锂：结果有启发，但时间不足，排除

### 3.1 数据边界

| 项目 | 范围 |
|---|---|
| `LC0` | 2023年7月21日至2026年9月15日 |
| 广期所仓单 | 2023年12月6日至2026年9月15日，共674个日度观测 |
| 可执行回测窗口 | 2024年1月2日至2026年9月11日 |
| 参数前窗 | 2024年 |
| 后窗 | 2025年1月2日至2026年9月11日 |

广期所在2023年12月6日之前没有碳酸锂仓单小计，因此当前窗口已经是同口径官方仓单能够支持的最长历史。社会库存与交易所仓单统计范围不同，不能拼接延长。

### 3.2 最终核心样本

- 融捷股份；
- 盛新锂能；
- 赣锋锂业；
- 天齐锂业；
- 永杉锂业。

西藏矿业已从最终样本移除。永杉锂业只能从其锂业务点时证据有效后进入组合，进一步缩短了五只股票共同有效历史。

### 3.3 排除理由

仓单连续仓位、MA20修复和低暴露防守链路在部分窗口中改善了收益或回撤，但不能形成跨周期证据：

- 完整历史不足三年；
- 只有约137个周度信号；
- 2024年前窗和2025年后的市场状态差异很大；
- 仓单只是交割库存，不是社会总库存；
- 更换核心股票后结果发生明显变化，样本选择敏感；
- 移动止损的低回撤依赖约10%的平均暴露，适合作为研究观察，但不足以固化成当前系统规则。

因此碳酸锂不进入正式策略，但保留每周Agent评估作为前向观察。广期所仓单同步继续运行；至少取得一个完整未来年度后再重新评审证据资格。

## 四、铝：数据合格，但库存模型失败

最终按用户指定的四只股票复核：

- 云铝股份；
- 宏桥控股；
- 神火股份；
- 天山铝业。

宏桥控股和天山铝业按商品业务点时证据生效，不能向更早历史回看。

| 组合 | 全窗口年化 | 全窗口最大回撤 | 后窗年化 | 后窗最大回撤 |
|---|---:|---:|---:|---:|
| 四只核心等权 | 16.9% | 76.0% | 19.4% | 46.4% |
| 10个百分点库存缓冲 | 16.3% | 66.1% | 15.8% | 40.1% |
| 20个百分点库存缓冲 | 15.3% | 67.5% | 13.6% | 38.4% |

库存覆盖降低了回撤，但后窗收益和风险调整结果不足以超过满仓核心等权；铝在商品仓位层即被否决，不继续技术入场与退出研究。

## 五、锌：库存模型失败且公司暴露混杂

最终样本为中金岭南、盛达资源、罗平锌电、西藏珠峰和驰宏锌锗。SHFE锌库存和`ZN0`历史长度均足够，但样本公司同时受到铅、银、锗等多金属影响。

| 组合 | 全窗口总收益 | 后窗年化 | 后窗最大回撤 |
|---|---:|---:|---:|
| 核心等权 | -11.4% | +12.2% | 50.0% |
| 10个百分点库存缓冲 | -9.0% | +5.3% | 41.2% |
| 20个百分点库存缓冲 | -2.4% | +7.0% | 42.4% |

连续库存仓位虽然减少部分回撤，但后窗收益只保留基线的43%～57%，不满足收益保留要求。锌被排除。

## 六、动力煤及其他品种

### 6.1 动力煤

沿海六大电厂存煤可用天数仅覆盖2016年1月1日至2019年6月21日；`ZC0`公开历史也止于2022年12月30日。该数据不能验证2020年至2026年的煤炭周期，因此排除。

CCTD秦皇岛港公开接口只能向前滚动积累近期数据，不能立即补齐同口径长期历史。不同口径的电厂可用天数、港口库存和交易所仓单不能拼接。

### 6.2 镍、铅、锡

虽然期货和交易所库存可取得，但A股中缺少足够的单一商品直接暴露公司：

- 镍行业直接成分过少，主要公司多为多金属或材料业务；
- 铅锌公司无法稳定拆分铅、锌利润暴露；
- 锡的纯上游核心股票不足以组成三至五只组合。

不为凑足股票数量而纳入加工、设备或概念公司。

## 七、最终系统边界

### 保留

- 商品和公司角色通用存储表；
- 铜库存、铜期货和铜核心公司数据；
- 铜确定性信号工具；
- 铜库存同步与周度Agent评估；
- 碳酸锂仓单数据同步与周度Agent前向观察；
- 各品种研究脚本和本地明细，用于复现。

### 不保留为当前研究信号


- 铝、锌、动力煤、镍、铅、锡的定时信号；
- 统一商品研究引擎；
- 统一商品Agent任务；
- 通用技术入场、止损、分批止盈和移动止损参数。
