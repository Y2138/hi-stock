# 盘中加减仓信号复盘结论

> 状态：只读复盘完成，结论用于规则调整，不改动历史信号。
> 数据窗口：2026-10-27 至 2026-11-10。
> 证据资格：`research_only`。

## 一、样本与口径

| 项目 | 数值 |
|---|---|
| 追加判断行数 | 2944 |
| 交易日 | 11 |
| 标的数 | 8 |
| 账户数 | 1 |
| add / reduce / wait | 32 / 178 / 2734 |
| 独立标的日 | 39（add 20、reduce 35） |

- 命中口径：基准价为信号行自身的最新价。add 记命中 = 价格上行；reduce 记命中 = 价格下行。
- 窗口：当日收盘、次日、3 日、5 日，均用前复权日线收盘价。
- 基线：同一窗口内 wait 信号的上行/下行占比，代表「不动作」。
- 2026-11-10 当日日线未入库，该日 322 行缺当日收盘窗口，其余窗口不受影响。
- 信号时刻集中在 09:30–14:59，09/10/11/13/14 点的样本分别为 382、733、341、724、748 行。

样本规模限制：add 只有 20 个标的日、reduce 只有 35 个，且同一天同一标的被反复采样，观测高度相关。**两组样本均不足以形成稳定结论**，下列命中率只用于识别方向性偏差，不作为胜率定论。

窗口收益均值：add 为 +0.51% / +0.85% / +3.81% / +1.47%；reduce 为 +1.19% / +1.49% / +1.41% / −1.26%。扣除同期沪深300 后的超额均值：add 为 +0.39% / +0.60% / +2.82% / +0.64%；reduce 为 +0.79% / +1.18% / +1.49% / −0.63%。

按「每标的日只取首笔」去重后结论不变：add 次日上行 8/16，reduce 次日下行 14/28；add 3 日上行 8/10，reduce 3 日下行 7/20。

统计判读：

- reduce 在当日收盘窗口比基线低 13.5 个百分点（z=−3.19，p=0.001），即减仓后到收盘多数反弹；这是唯一达到常规显著水平的负向结果。
- reduce 在次日与 3 日窗口相对基线分别为 −2.1 和 −8.7 个百分点，置信区间覆盖基线，等于没有预测力。
- reduce 在 5 日窗口比基线高 21.3 个百分点（z=2.79，p=0.005），但 44 行里 20 行来自 10-27 的川润股份与国恩股份两只标的，实际独立样本只有 2 个标的日。
- add 在 3 日窗口比基线高 36.0 个百分点（z=2.77，p=0.006），但 15 行里 8 行是亚钾国际，5 行集中在 11-02、11-03，同样属于单票单日主导。
- 两组置信区间普遍宽达 15–35 个百分点，任何一个窗口都无法支撑「胜率高于/低于基线」的定论。

其他结构性事实：

- reduce 信号价平均落在当日振幅 36% 分位、距当日最高 −4.0%；add 落在 51% 分位、距当日最高 −2.9%。
- 情绪分布为 strong 1679、neutral 723、weak 443、unknown 99、ice_point 0。窗口内每日涨停均值 26–80 只，跌停峰值多在 2–27 只，10-22、10-23、10-29 盘中到过 44–58 只，10-30 午后到过 87 只但当日涨停均值仍 44 只，属分化而非冰点，因此该窗口没有冰点样本。
- 抖动：39 个标的日共发生 330 次动作切换，平均每个标的日 8.5 次，单标的单日最多 25 次；同向重复信号的相邻间隔中位 9 分钟、75 分位 49 分钟，68% 落在 30 分钟以内。
- 首笔与后续同向信号表现无差异：reduce 首笔次日下行 50.0%、后续 49.5%；add 首笔次日上行 50.0%、后续 55.6%。
- 价格基准无偏差：全部信号的最新价都落在当日最高最低之间，与当日收盘的偏差中位 +0.08%、均值 −0.18%；最新判断行的行情滞后 95 分位约 4 秒。

## 四、结论

1. 减仓信号在 1 至 3 日维度没有预测力，在当日收盘维度显著反向。减仓之后价格平均上行（次日 +1.49%、3 日 +1.41%），相对沪深300 也跑输，说明减仓多数发生在下跌尾声而非下跌起点。
2. 减仓的失效与信号价所处位置强相关。信号价落在当日振幅 30% 以下时，次日下行概率只有 21.1%、均值 +6.13%；30% 分位以上才转为负向（66.7%–76.7%）。追跌是减仓失效的主因。
3. 减仓的失效与情绪分档强相关。strong 情绪下减仓次日下行 62%–66%，weak/neutral 下早盘减仓次日下行只有 26.8%、均值 +5.92%。弱市与平稳市的减仓属于割在低位。
4. 加仓样本不足以判断有效性。32 行集中在 strong（19）与 neutral（12），没有冰点样本，无法验证冰点反向加仓；日内分位越低次日表现越好，但每档只有 2–11 行。
5. 抖动放大了样本。原始 2944 行压缩到 39 个标的日，平均每个标的日切换 8.5 次，同一事件被连续重述，导致命中率的有效样本远小于行数。
6. 本轮不支持停用加减仓提醒，也不支持把减仓当作已具备正期望的动作。需要按位置与情绪加闸门、按冷却口径去抖，再积累至少 3 个月、add 不少于 60 个标的日的数据复评。
