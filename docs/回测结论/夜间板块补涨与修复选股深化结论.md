# 夜间板块补涨与修复选股深化结论

> 验证日期：2026-10-10。证据等级：研究候选（research_only）。正式评估沿用2022至2026年的372个冻结行业事件，不扩展2021年以前的回测。2021年行业数据及更早的必要个股种子仅用于指标预热。

## 一、最终结论

**保留补涨与修复两条观察路线，不把组合或追加修复条件认定为收益增强。**

单独选20日表现最弱的两只，固定20日净均值 +5.26%；补涨与修复各一只为 +5.22%，配对差 -0.05 个百分点，月块区间 [-0.67，+0.54] 个百分点。按信号日等权，各一只增加约0.11个百分点，区间 [-1.04，+1.12]，仍不能确认改进。

修复候选中再挑20日表现最弱的两只，为 +4.82%，比单独补涨少0.44个百分点，配对区间 [-1.22，+0.26]。更严格确认没有证明能提高20日收益，也没有保证尾部风险更小。

当前证据支持把“单独补涨”和“补涨修复各一只”冻结为两个前瞻观察版本；修复条件作为单独的证据标签与候选资格保留，暂不增加综合分或新的最优参数。没有接入生产任务，不形成买卖指令。

## 二、信号、样本与价格口径

### 固定窗口

根证据为 `支撑/tmp/夜间板块双线趋势回测/独立结论复核-2026-10-10-786a4c73ec92.json`。保持60日下降趋势、滚动回归线穿越、短期斜率、15日止跌证据、量比及15日冷却规则，使用同一批372个信号，不根据选股收益重新择时。

股价、行业、当前成分与财务来自PostgreSQL一致性只读快照；股数、费用和成交采用原始价格，特征不使用当前锚点前复权。

### 成分与覆盖

当前881行业的沪深主板成分3196只；最近120个开市日具备合法原始日线、近20日成交量为正且单位为股、20日平均成交额至少2000万元的股票进入候选。120日预热依照 `market_trading_day` 的已确认开市日，行业beta还要求60日连续行业价格；板块日线首日不作为股票预热的首日。

查询原始日线3909628根，得到3073只股票的11078个候选事件；因行情或连续预热不足排除1046个成员事件，因成交额不足排除696个成员事件。371个板块事件至少有5只候选；2个事件不可共同结算，主比较为369个事件、122个信号日期、33个信号月份。

不足5只候选的事件是2022-05-09的 `881167.TI`；不可共同结算的事件包括2022-05-18的 `881157.TI`（`002670.SZ`无法在退出与顺延期内卖出），以及2022-10-21的 `881145.TI`（`601016.SH`涉及未建模配股）。不以事后收益单独删除某只股票并保留其余选择方案；不可结算整组隔离仍属于数据限制，不是当时的选股资格。

### 公司行动与除权

研究使用只读导出的全市场事件快照，窗口2020-01-14至2026-09-24，共27138条、5008个代码；与PostgreSQL中的事件按股票与除权日合并，PostgreSQL现金与送转记录优先；批量事件流已明确提供的配股权益，不被REST缺字段形成的0值覆盖。本次保留12条明确的配股权益。合并输入20914条事件，2868只当前主板成员有事件记录。

每只股票按原始收盘与已合并事件重算除权参考前收，连接因果价格特征；快照中有4910根前收参考值与原存值不同。除息日开盘跳空相对除权参考价计算，信号前低在入场除权日同步变换。持有期间现金分红按短持20%税率保守计提，送转调整股数，现金不再投资；配股入场和持有中配股均不建模，不能结算的事件整组隔离。

有事件记录不等于证明完整覆盖，没有事件记录也不等于一定缺失。研究快照截止日之后的事件及原始历史版本仍需核验；没有改写PostgreSQL行情或公司行动表。

### 资金、成交与退出

- 每个板块事件10万元，两个5万元槽位；买入100股整数手，每股容量不超过过去20日平均股数的2%。
- 次日开盘入场，上跳空超过除权参考价3%放弃；未成交或不足两只的槽位留现金，不替补第三名。
- 正常实验主板涨跌停边界按10%近似；未来开盘价格只用于成交判断，不进入选择排序。
- 佣金单边2.5bp、最低5元；卖出印花税2023-08-28前10bp、之后5bp；单边滑点10bp，压力30bp。
- 主比较持有第20日收盘形成退出，次日开盘卖出；不可卖时最多额外顺延10日，不能结算记缺口。
- 辅助保护线为 `max(入场除权口径的信号前20日低点, 入场价×0.92)`，收盘触发、次日开盘退出；后续除权同步调整保护线。8%触发线不保证最大亏损8%。

各板块事件独立模拟，不能将重叠事件均值当作年化、资金组合收益或组合回撤。

## 三、四个选股版本

| 版本 | 冻结选择原则 |
|---|---|
| A：20日跌幅靠前 | 同板块同资格股票按20日涨跌幅从低到高，取两只；不另调跌幅阈值 |
| B：止跌修复确认 | 20日收益<0、5日收益>0、收盘>MA10、MA20乖离≤10%；按5日行业残差从高到低取两只 |
| C：修复后按跌幅选股 | 使用B的资格条件，再按20日涨跌幅从低到高取两只 |
| D：补涨修复各一只 | 先取A第一只，再从其余股票中取B第一只；没有修复候选时第二槽留现金 |

B的残差由过去60日股票对所属行业的日对数收益回归beta、截距解释，减去过去5日行业解释部分得到。所有排序只使用信号收盘可得数据；同分按代码排序，不能依据未来收益破同分。

C、D是独立实验规则，不继承A、B的成绩；它们未作为生产组合或正式评分权重。

## 六、候选策略与前瞻验收

1. 保持宏观与板块窗口不变，继续记录完整成分和板块证据。
2. 首要观察版本保留A；另行并行记录D。两组都必须复核当日真实交易资格、ST、停牌、上市初期与缺数，价格信号不替代这些风险检查。
3. B作为修复证据和独立观察版本，不强行把它变成所有补涨标的的硬门槛；C没有稳定改进证据，暂不增加为主要生产选择。
4. 每只候选记录路线、同板块20日位置、5日修复、MA10/MA20、行业残差、失效位、财务与公告可得日期；模型负责解释，不能凭文字提高条件等级。
5. 前瞻记录A、D及同日候选与板块基准。未成交、缺数、第二槽为空和结构失效必须保留；按独立信号日期及完成20日窗口的事件数验收，不因运行满一定天数就宣告通过。
6. 验收同时看日期等权超额、中位数、尾部、可成交率、失效率和关键反弹阶段分布。规则冻结后不根据后续某一轮成绩临时调整排序。

这是一份研究候选结论，不是已经完成前瞻验收的正式个股入场策略；本轮没有修改生产任务、关注池、持仓或数据库。

## 七、证据边界与复现

- 当前成分记录从2026-08-20开始，所有冻结事件仍缺少完整当时成分，存在分类和幸存者偏差。
- 研究只覆盖当前行业中的主板及已具备原始数据的候选，不外推到其他板块。
- 原始股价与公司行动快照不证明完整历史ST、特殊制度、停牌原因、退市结算与订单队列；日线成交模型仍是近似。
- 财务仅按报告日字段对齐，没有当时原始版本与修订轨迹。财务和公告风险复核需要独立证据，不用最新估值回填历史。
- 本轮参数、组合及对照均在已观察数据上研究，月块区间未校正多重比较与全部跨月相关，不构成样本外。
