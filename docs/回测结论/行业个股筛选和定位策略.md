# 行业个股筛选和定位策略

## 一、结论

“先判断商品供需和库存，再利用期货价格确认，最后选择对应股票”的方向成立，但只适用于**盈利对某种商品价格具有稳定、可解释暴露的公司**，不能直接推广到所有周期行业，也不能把期货上涨简单等同于矿业股应当上涨。

更完整的传导链是：

> 宏观与终端需求 → 矿山、冶炼和再生供给 → 显性及隐性库存 → 现货升贴水和期货曲线 → 商品价格 → 公司实际售价、产量和单位成本 → 利润及现金流变化 → 估值、风险偏好和资金定价 → 股票收益

因此，供给、需求和库存是起点，不是完整策略。期货价格是市场对这些信息的综合定价之一，可能领先股票，也可能已经提前反映预期；只有在商品基本面、公司利润弹性、估值和股票交易结构同时成立时，才可能形成可执行机会。

合理的策略形态不是纯左侧或纯右侧，而是三层组合：

1. **基本面状态层**：判断商品处于宽松、改善、紧张还是恶化阶段。
2. **公司筛选和估值层**：判断哪些公司真正受益，以及当前股价是否已经透支预期。
3. **价格执行层**：用期货和股票价格结构确定确认、入场、退出与风控。

## 二、适用范围必须先收窄

原看法中列举的行业不能使用同一模型，应至少分为以下类型分别研究：

| 类型 | 典型对象 | 主要利润锚 | 是否适合商品联动模型 |
|---|---|---|---|
| 上游资源生产商 | 铜矿、金矿、煤矿、油气开采 | 商品售价减现金成本 | 最适合 |
| 矿冶一体化公司 | 采矿、冶炼同时存在 | 自产矿利润、冶炼利润和副产品共同决定 | 适合，但需拆分业务 |
| 冶炼商 | 铜冶炼、铝冶炼 | 加工费、能源成本、开工率和库存收益 | 不能简单按商品上涨受益处理 |
| 材料加工商 | 铜箔、电缆、合金、化纤 | 加工费、订单、库存计价和转嫁能力 | 商品上涨可能挤压利润 |
| 设备制造商 | 风电设备、矿山设备 | 订单、招标价格、原材料成本和产能利用率 | 应使用制造业模型 |
| 金融周期行业 | 保险等 | 利率、资产收益率、负债成本和信用周期 | 不属于商品锚定模型 |
| 运输周期行业 | 航运 | 运价、船队供给、港口效率和燃料成本 | 可用供需框架，但锚定对象是运力而非商品价格 |

以铜为例，同一“铜”板块可能同时包含矿企、冶炼商、加工商和矿山服务商。它们对铜价、铜精矿加工费和能源成本的敏感度可能方向相反，不能直接放入同一股票池排序。

## 三、需要补充的影响因素

### 3.1 商品供需与库存

| 维度 | 关键因素 | 解释 |
|---|---|---|
| 矿山供给 | 产量、品位、回收率、新增项目、扩产进度、罢工、事故、天气、许可 | 名义产能不等于实际可交付产量 |
| 冶炼供给 | 冶炼产量、开工率、检修、精矿供应、加工费 | 精矿紧张可能利好矿企但压缩冶炼利润 |
| 再生供给 | 废铜回收量、价差、政策和进口 | 再生供给会缓冲原生铜短缺 |
| 终端需求 | 电网、地产、家电、汽车、电子、机械、数据中心和新能源投资 | 需要区分真实消费、渠道补库和政策脉冲 |
| 贸易流 | 精矿、精炼铜、废铜进出口，区域升贴水和跨市场套利 | 全球总量平衡不代表中国现货一定紧张 |
| 库存 | 交易所库存、保税库存、社会库存、生产商和消费商库存 | 单看交易所库存会遗漏大量隐性库存 |
| 库存效率 | 库存消费天数、库存变化速度、季节性分位 | 绝对库存必须结合消费规模和季节性解释 |

库存下降也不能自动解释为需求走强，还可能来自仓单注销、跨地区搬运、融资变化、出口套利或统计口径变化。ICSG也明确指出，中国未报告库存变化可能显著改变表观供需平衡，因此回测必须区分显性库存与无法观测的库存缺口。

### 3.2 期货和现货定价

- 现货价、近月和远月价格，而不是只看一条主力连续收盘价。
- 期限结构：升水、贴水、近远月价差及其变化。
- 现货升贴水、跨交易所价差、进口盈亏和汇率折算。
- 成交量、持仓量、换月和交割月效应。
- 期货连续合约的换月规则、复权方式和可交易性。
- 价格趋势、波动率和跳空，但不能把同一价格既用于形成信号又用未经延迟的价格成交。

期货可能比股票更快反映商品信息，但“反映更快”不等于稳定预测股票。期货收益、库存和期限结构应先作为候选解释变量，通过滚动窗口检验其领先关系是否稳定。

### 3.3 宏观与流动性

- 中国及全球制造业景气、工业生产、固定资产和电网投资。
- 美元汇率、人民币汇率、实际利率和全球信用条件。
- 能源、运费和关键辅料成本。
- 国内稳增长、地产、环保、进出口、储备收放和产业政策。
- 风险偏好、权益市场整体状态和行业资金拥挤度。

“加息必然压制铜价”不能作为固定规则。利率、美元和铜价可能同时受到增长、通胀和风险事件驱动，应按不同宏观状态分别检验，而不是只检验全样本相关性。

### 3.4 公司利润弹性

| 维度 | 必要信息 |
|---|---|
| 商品暴露 | 铜相关收入、利润、自产矿和外购原料占比，副产品贡献 |
| 产量 | 权益产量、销量、产能利用率、品位、回收率和扩产兑现情况 |
| 成本 | 现金成本、完全成本、能源、人工、运费、税费和特许权使用费 |
| 套期保值 | 套保比例、期限、价格和实际结算价，长期销售合同 |
| 资源质量 | 储量、资源量、剩余矿山寿命、资本开支和维持性资本开支 |
| 地域风险 | 矿区国家、税制、汇兑、制裁、社区、许可和运输通道 |
| 财务风险 | 净负债、利息覆盖、再融资、少数股东权益和潜在摊薄 |
| 治理和兑现 | 并购质量、项目延期、减值、关联交易和历史指引兑现率 |

商品价格上涨时，低成本、未过度套保、产量可兑现且资产负债表稳健的生产商通常具有更清晰的利润弹性；高成本、重资本开支、过度套保或产量下降的公司可能无法同步受益。

### 3.5 估值与股票市场因素

- 周期股不能只看静态市盈率。商品价格高位会抬高当期利润并压低PE，低PE反而可能出现在盈利周期顶部。
- 优先研究中周期利润、单位资源价值、EV/EBITDA、自由现金流收益率、PB与ROE匹配、净负债和商品价格敏感性。
- 估值必须使用当时已经公开的数据，不能用报告期结束日替代实际披露日。
- 还需控制市值、流动性、停牌、涨跌停、股权融资、分红除权和上市退市偏差。
- 个股对铜价的历史滚动Beta可以用于验证暴露，但不能替代业务拆分；Beta会随业务结构、套保和市场风格变化。

## 四、数据需求与当前系统缺口

### 4.1 首期最小数据集

首期只验证“铜价趋势 + 库存变化 + 公司业务类型”是否比纯股票趋势提供增量价值，只保留四类数据：

| 数据集 | 推荐频率 | 用途 | 当前状态 |
|---|---|---|---|
| `CU0` 主力连续 | 日 | 判断20、60日铜价趋势 | 已完成2014年至今回填 |
| SHFE铜总库存 | 周 | 计算4周库存变化方向 | 已回填2015年至今 |
| 公司铜业务角色 | 事件 | 只保留上游矿企和矿冶一体化公司 | 已录入5只核心样本 |
| A股日线和现有财务指标 | 日/年 | 股票执行、流动性和基础财务风险过滤 | 已具备 |

首期不采集LME、ICSG、海关、PMI、实际利率、现货升贴水、TC/RC、矿山产量、现金成本、储量、套保、地缘事件和历史估值。只有最小模型样本外有效时，才按消融结果补充期限结构或公司经营指标。

### 4.2 截至2026年9月15日的本地事实

当前 PostgreSQL 已具备较好的A股价格研究基础，但尚不具备完整的商品基本面回测输入：

- `market_bar` 有约1165万条股票、指数和板块日线，主要A股研究窗口可覆盖2016年至2026年。
- 当前4条期货主力连续中，沪铜 `CU0` 已回填2014年1月2日至2026年9月15日共3092条，可用于长期价格状态研究。
- 当前“铜”板块有16只现行成分，但成分关系从2026年8月21日才开始留痕；首期不回填整板块历史，只使用5只有年度报告点时证据的核心生产商，结果保持研究资格。
- 历史财务已有4923条、覆盖520只股票，主要是年度共同报告期；不足以覆盖全部铜相关股票的季度经营数据和产量、成本、储量、套保等商品暴露。
- 估值表只有约522条近期快照，不支持历史点时估值回测。
- 上期所铜真实合约已保存2026年1月5日至2026年9月15日共2052条结算持仓记录和171个交易日主力映射；铜总库存已保存2015年1月9日至2026年9月11日共598周；公司角色已保存铜陵有色、云南铜业、江西铜业、西部矿业和洛阳钼业5只核心样本。
- 现有标准日频回测输入只包含股票日线、881环境日线和可选基准，不能直接冻结期货曲线、库存、宏观和公司点时暴露。

因此，现有数据只能做两类有限研究：

1. 使用现行铜板块股票历史行情进行**探索性技术关系分析**，结果不得视为无幸存者偏差的正式证据。
2. 使用2014年以来的 `CU0` 研究长期铜价状态，并使用2026年真实合约做期限结构、主力换月和短窗口领先滞后诊断；缺少长期真实合约和库存数据时仍不能宣称完整供需策略跨周期有效。

首期最小数据集已经具备，可以开始只读研究回测。

### 4.3 数据保存设计

当前系统并非完全没有期货存储，而是采用统一行情模型：

- 期货标的保存在 `market_instrument`，`kind='futures'`。
- 期货日线保存在 `market_bar`，`freq='futures_day'`。
- 当前 `CU0`、`AL0`、`NI0`、`LC0` 都按这一方式保存，日更任务会自动查询全部 `kind='futures'` 标的并更新。

这种结构足以保存主力连续OHLCV，但不足以保存合约曲线、结算价、持仓量、库存、供需和公司商品暴露。实现继续复用现有统一行情表，只为新增语义增加专用表，不另建一套重复的期货K线系统。

#### 4.3.1 期货价格

| 数据 | 保存位置 | 说明 |
|---|---|---|
| 主力连续和单合约OHLCV | 复用 `market_instrument` + `market_bar` | 每个单合约也是一个 `kind='futures'` 标的，例如使用带交易所和交割月的稳定内部代码 |
| 交易所、品种、合约月、乘数、报价单位和最后交易日 | `market_futures_contract` | 区分单合约、主力连续和近月连续，禁止只靠代码字符串推断 |
| 结算价、前结算价、持仓量和涨跌停价 | `market_futures_daily_detail` | 以 `instrument_id + trade_date` 唯一；OHLCV仍留在 `market_bar`，不重复存储 |
| 连续合约每日对应的真实合约 | `market_futures_roll` | 保存主力合约映射、换月原因和调整因子，保证回测可重放 |

主力连续只能用于趋势观察，不能替代真实合约曲线。期限结构必须由同一交易日的多个真实合约计算；换月映射必须保存，不能每次回测时按当前算法重新猜测。

#### 4.3.2 商品、库存和宏观序列

已新增两张通用点时时序表：

| 表 | 核心字段 | 用途 |
|---|---|---|
| `market_factor_series` | `series_code`、商品、市场、指标、频率、单位、来源、时区 | 定义 `SHFE铜库存`、`LME铜库存`、`铜现货升贴水`、`ICSG精炼铜使用量`、`制造业PMI` 等稳定序列 |
| `market_factor_observation` | `series_id`、观测期、`published_at`、数值、修订号、来源引用、原始摘要、抓取时间 | 保存每次首次发布和后续修订，支持按回测时点查询当时真正可见的值 |

最重要的字段不是抓取时间，而是：

- `observation_date`或报告期：这个数字描述哪个时期。
- `published_at`：市场最早何时能够知道这个数字。
- `revision_no`：后续是否发生修订。
- `unit`和来源口径：吨、万吨、美元/吨、人民币/吨和百分比不能混用。

历史值不得直接覆盖。回测按信号时刻选择 `published_at` 不晚于该时刻的最新修订，才能避免把未来修订后的数据用于过去。

#### 4.3.3 公司商品暴露

产量、成本、储量和套保不写入 `fundamental_snapshot.raw_summary`，已新增：

| 表 | 核心字段 | 用途 |
|---|---|---|
| `company_commodity_profile` | 股票、商品、业务角色、生效区间、披露时间、来源证据 | 区分矿企、矿冶一体化、冶炼、加工和服务公司，并保存历史角色变化 |
| `company_commodity_metric` | 股票、商品、报告期、披露时间、指标代码、数值、单位、来源摘要 | 保存权益产量、销量、现金成本、储量、套保比例、资本开支和商品利润占比 |

采用“指标代码 + 数值 + 单位”而不是一次建立大量可空列，是因为不同公司披露口径不同；但指标代码必须来自服务端白名单，不能让Agent自由创造字段。

#### 4.3.4 数据写入和分发边界

- 新表通过只向前迁移创建，所有写入必须经过 `server/datasource/` 领域服务。
- 调度任务只调用固定同步服务，并继续使用 `market_fetch_run` 记录范围、来源、写入行数和缺口。
- PostgreSQL仍是运行时唯一事实源；研究脚本只能只读查询，不能直接写业务表。
- 商品、期货、公司暴露和宏观历史属于本机运行数据，不进入Git固定资产、便携包或策略正文。
- `hithink_dataset_snapshot` 只适合保存特定请求的最新快照，不能替代可查询、可修订的历史点时时序表。

#### 4.3.5 回测输入

现有标准回测只读取 `market_bar.freq='day'` 的A股、板块和基准日线，即使数据库已经保存 `futures_day`，标准引擎也不会自动使用。

第一步研究可以由独立只读脚本直接联查上述表。只有研究通过后，才扩展标准冻结输入，分别加入：

- `futures_bars`：期货及真实合约行情，只作为外生信号，不混入股票可交易集合。
- `market_factors`：截至当日已发布的库存、期限结构、供需和宏观观测。
- `company_factors`：截至当日有效的公司业务角色和商品暴露。

冻结输入应保存原始点时观测和来源版本，因子分数由固定引擎确定性计算；不要只冻结最终综合评分，否则无法做单因子消融和复核。

## 五、可执行的回测计划

### 5.1 研究对象

第一期只研究铜，且将股票拆成独立组：

1. 上游铜矿生产商。
2. 矿冶一体化公司。
3. 冶炼商。
4. 铜材加工商。
5. 矿山服务和其他弱铜价暴露公司。

主策略只在前两组内形成组合；后三组分别作为对照，不混入同一排序。每家公司必须有点时有效的业务分类和铜利润暴露证据。

### 5.2 待检验假设

| 编号 | 假设 | 否证条件 |
|---|---|---|
| H1 | `CU0` 20日和60日趋势对铜矿股未来20日收益有增量解释力 | 只解释同期收益，或样本外不优于股票趋势 |
| H2 | SHFE铜总库存连续4周下降能改善铜价趋势信号 | 加入库存后收益、回撤和稳定性没有改善 |
| H3 | 上游矿企和矿冶一体化公司比混合铜板块更能响应铜价状态 | 分组结果不稳定，或收益仍由加工和题材公司贡献 |

### 5.3 首期因子

只使用四项：

1. `CU0` 20日收益。
2. `CU0` 60日收益。
3. SHFE铜总库存4周变化率。
4. 股票相对铜板块20日强度。

公司业务角色只用于限定股票范围，不参与复杂评分；现有财务数据只排除明显现金流或负债风险，不增加新的估值模型。

### 5.4 实验组和基线

| 组别 | 内容 |
|---|---|
| 基线A | 上游及矿冶一体化股票等权持有 |
| 基线B | 只使用股票相对强度 |
| 基线C | `CU0` 趋势过滤 + 股票相对强度 |
| 实验D | `CU0` 趋势 + SHFE库存4周变化 + 股票相对强度 |

只有实验D在样本外和净成本后稳定优于基线B、C，才继续补期限结构或公司经营数据；否则停止扩充数据源，保留更简单的价格策略。

### 5.5 时间与成交规则

- `CU0` 使用2014年1月2日至2026年9月15日；组合共同窗口以库存历史可用起点为准。
- 库存周报只在发布后的下一交易日进入信号，公司角色只在对应证据披露后生效。
- 每周库存更新后计算一次状态，股票信号在当日收盘形成，最早按下一交易日开盘成交。
- 执行A股T+1、100股整数手、停牌、涨跌停、成交量参与率、佣金、印花税和滑点。
- 期货只作为外生信号，不计算期货持仓收益。

### 5.6 样本外与稳健性

- 使用扩展窗口滚动验证，例如前三年训练、下一年测试，参数只在训练窗选择。
- 单独报告2016—2019、2020—2022、2023—2026年8月三个市场阶段。
- 对库存发布时间增加1至5个交易日额外延迟，验证结果是否依赖发布时间边界。
- 使用10、30、50个基点滑点压力测试。
- 剔除单只股票、单一年份和最优若干交易，检查结果是否过度集中。
- 分别对上游矿企、矿冶一体化和加工企业回测，不允许事后只保留表现最好的子组并宣称全行业有效。

### 5.7 评价指标和通过条件

除总收益外，至少报告：年化收益、最大回撤、Calmar、波动率、换手率、持仓暴露、胜率、盈亏比、分年度收益、公司贡献、因子IC及其稳定性。

策略进入标准回测的最低条件：

1. 样本外净成本结果同时优于纯股票趋势和纯铜期货趋势基线。
2. 在不同年份、不同滑点和不同数据延迟下保持相同方向。
3. 收益不依赖单只股票、单一年份或少数极端交易。
4. 公司分组结果符合可解释的利润弹性顺序。
5. 使用历史有效股票范围、真实披露时间和可复现的期货换月规则。

## 六、在本仓库中的落地顺序

1. **存储层已完成**：迁移 `0097_商品期货点时研究数据.sql` 已建立期货合约、换月、商品因子和公司商品暴露表；`server/datasource/commodity-service.ts` 提供受控幂等写入、点时修订保护和抓取留痕。
2. **上期所真实合约同步已完成**：`server/datasource/shfe.ts` 读取上期所官方日行情，`shfe-service.ts` 保存铜真实合约K线、结算价、持仓量和按持仓量确定的主力映射；工作日16:20由 `commodity_copper_sync` 自动执行。
3. **长期回填入口已完成**：`npm run datasource:shfe-futures-backfill -- --start YYYY-MM-DD --end YYYY-MM-DD --product CU` 按本地交易日历幂等回填；正式运行库已回填 `CU0` 的2014年至今数据和2026年以来的真实合约。
4. **最小数据已完成**：铜总库存回填598周并由 `commodity_copper_inventory_sync` 每周五17:10更新；5只核心生产商已按年度报告披露时间录入业务角色。
5. **下一步做只读研究**：新增独立研究脚本读取PostgreSQL，输出数据覆盖、领先滞后、因子分组、消融和组合结果；该结果只作为研究证据。

7. **标准运行后再讨论策略采纳**：正式结论必须来自不可变输入、固定规则、样本外验证和可重放结果；不得把自由研究脚本结果直接作为发布收益证据。

最小可行实施不应一开始覆盖煤炭、贵金属、航运、保险等全部周期行业。先把铜的“数据—因果链—公司暴露—回测”闭环做完整，再判断哪些结构能够复用。

## 七、首期回测裁定

铜价趋势、库存下降和个股相对强度组成的硬门禁策略已否决；库存只适合作为连续仓位调节候选。

当前保留的唯一候选为：五只核心生产商等权，50%底仓，另50%仓位按SHFE铜库存4周变化的历史逆百分位调节，目标仓位变化不足20个百分点时不调仓。全窗口净收益+419.9%、年化18.7%、最大回撤48.0%，对照满仓等权为+424.7%、18.8%和56.4%；2023年至2026年后窗候选收益+158.4%、最大回撤27.9%，对照为+228.2%和39.4%。

候选定位是防守仓位覆盖层，不是超额收益或选股策略。它保持研究资格，不继续扩充数据源，不进入生产策略。完整结论见 `docs/回测结论/大宗商品相关标的最终回测结论.md`。
