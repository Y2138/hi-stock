# 江西铜业左侧启动策略最终结论

> 截止：2026-09-21。研究结果不构成自动交易指令；正式策略只生成结构化入场、接近候选和持仓退出提醒。

## 策略范围

唯一入场标的为江西铜业（600362.SH）。铜陵有色、云南铜业、北方铜业只用于计算退出时的MA60宽度；西部矿业和洛阳钼业未通过同参数独立验证，不扩入正式扫描池。

原铜库存仓位策略与碳酸锂仓单策略均从当前系统移除。SHFE铜库存及OECD G7/中国CLI仍按原来源同步，用于江西铜业入场的宏观与供给证据；库存不再给出目标仓位。

## 入场与出场

T日收盘同时满足以下条件，产生下一交易日开盘入场提醒：

1. 当前收盘价较近252个交易日最高收盘价回撤15%～40%；
2. 较近60个交易日最低收盘价反弹8%～15%；
3. 该60日最低收盘价距离T日不超过30个交易日；
4. G7增长、中国需求、SHFE铜库存供给约束中至少两项正常；
5. 标的未持仓且当前没有重复信号。

G7 CLI不低于99.5或不低于三个月前；中国CLI真实月频三个月均值不低于99或不低于三个月前；SHFE铜库存十二周增幅不超过25%或库存不高于近三年70%分位。OECD按报告月末后45日作为保守可获得时间，历史使用最新修订版，存在修订偏差。

持仓后，江西铜业收盘价低于MA60、CU0收盘价低于MA60、四只参考铜股站上MA60的比例低于50%，三项**同时连续10个交易日**成立时，于下一交易日开盘形成全部退出提醒。无固定止盈和库存单项退出。关键数据缺失时部分完成，不生成正式信号。

## 回测验收

统一从本地PostgreSQL点时序列重跑最终T0规则；区间为2016-09-12至2026-09-11，包含佣金、印花税、10bp滑点和100股整手。回测按100%可用资金计算，不代表用户真实账户应满仓。

| 窗口 | 静态持有收益/回撤 | T0收益/回撤 | T0平均暴露 | 同仓位择时超额 |
|---|---:|---:|---:|---:|
| 全窗 | +352.4% / 55.6% | **+403.7% / 51.2%** | 54.8% | +210.3个百分点 |
| 前窗（截至2022-12-30） | +44.6% / 55.6% | **+87.2% / 51.2%** | 50.6% | +64.6个百分点 |
| 后窗（2023-01-03起） | +213.7% / 44.7% | +168.9% / 49.4% | 61.9% | +36.7个百分点 |
| 2021—2024独立窗口 | +13.8% / 55.6% | +1.6% / 51.2% | 36.5% | **-3.5个百分点** |

30bp滑点并延迟5个交易日：全窗收益+349.7%，最大回撤53.1%、同仓位超额+158.0个百分点；后窗收益+142.9%，同仓位超额+12.3个百分点。

最终规则在全窗超过静态收益并降低回撤，且前后窗同仓位超额均为正；但**后窗绝对收益低于满仓静态、回撤更高，2021—2024同仓位超额为负**。因此正式用途是确定性机会与风险提醒，不承诺跨窗口稳定超额。样本只锚定江西铜业，不能外推全铜股。

## 当前系统边界

- `copper_left_launch_signal_scan` 独立运行入场评估，正式和接近候选按策略归属关注池；持仓退出由每日计划按持仓策略调用。
- `commodity_copper_macro_sync`、`commodity_copper_inventory_sync` 继续提供数据；历史库存目标仓位及碳酸锂研究任务不再运行。
- 旧任务与策略的私有运行审计保留于现有数据库，但不进入当前策略目录、任务中心或可移植固定资产；已应用迁移按只向前规则保留。

复现：`npm run backtest:jiangxi-copper-two-stage`。脚本只读取PostgreSQL，结果输出至 `支撑/tmp/江西铜业两阶段结构回测/`，不写业务表。
