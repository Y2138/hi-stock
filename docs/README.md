## 三、维护规则

1. 新增内容先判断属于哪个功能 PRD 或哪类回测结论，并入已有入口，不按日期或评审过程另建文件。
2. 评审意见、实施状态、一次性对账记录不长期保留；最终约束回写到对应 PRD。
3. 被新版完整取代的文档直接删除，追溯使用 Git 历史；已应用的迁移文件不改名、不改内容。
4. 回测结论必须标注证据等级、适用窗口和是否进入生产；不得把研究结果写成收益承诺。
