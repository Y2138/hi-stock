运行时策略正文以 PostgreSQL `strategy_document` 为准：`portfolio` 角色是《投资总策略》（组合统筹），`task` 角色是各定时任务对应的任务策略文档（`job_code` 关联任务），`guidance` 角色是专项指引。

本地回测结论进入系统的链路是“本地回测 → 整理成任务策略文档 → 迁移写入”。回测本身在仓库内以脚本执行，系统内没有回测工具、回测页面或回测数据表；内置 Agent 不发起回测，也不发布或改写策略，只读取沉淀后的任务策略文档与任务工具结果。上述文件只保留研究依据、实现口径和可复现说明。

## 五、维护规则

1. 新增文档先判断是否属于产品、设计、策略、研究结论或部署；同类结论合并到已有入口，不按日期另建过程稿。
2. 评审意见、实施状态和一次性对账记录不长期保留；最终约束回写到对应主文档。
3. 已退役方案、被新版完整取代的版本和仅为追溯保留的历史文档直接删除，需要追溯时使用 Git 历史。
4. 回测结论必须标注证据等级、适用窗口和是否进入生产；不得把研究结果写成收益承诺。
