# A股研究台账展示契约

## 2026-11-23：目标口径v2.0与综合研判口径v1.0

03固定列序（九列）：日期 / 标的 / 当前价 / 位置 / 结构关注位 / 盈亏比 / 推荐度 / 四面读数 / 是否值得入场。2026-11-23起新增行按本节书写，此前各行保留原文，不回改。

「四面读数」写短句，如“基本面 中性｜技术面 偏多｜消息面 待核｜盈亏比 1.6:1 到前高”。四个面是基本面、技术面、消息面、盈亏比，每面读数取利多、偏多、中性、偏空、利空、待核。证据放正文每只标的的“综合研判”小节，逐面列读数、关键证据（带日期与来源）和缺口。

「是否值得入场」是综合研判的四档结论：值得入场、可小仓试、观察、不入场。结论句写三样：结论；主要依据是哪几条证据；主要风险或下一步观察点。

不作单项门禁：推荐度不低于70、收盘站上MA20、盈亏比不低于2、承接结构确认、ATR14/P不超过5%、风险距离2%—10%，这些照旧计算和展示，但只作读数与证据。任何一项不满足都不单独否决，也不单独放行。盈亏比无法量化时，结论照常综合其余三个面给出，并把“风险距离暂无法量化”写进主要风险。

盈亏比目标只取强压力位：前高（回看250个交易日内最高的已确认高点）或成交密集区价格中枢（连续3个及以上、每日成交量不低于此前20个交易日均量1.5倍的交易日，取成交量加权典型价格），取现价上方最近的一处。MA20、MA60与震荡高低点只作观察位。承接未确认、风险尺度不适配或贴近强压力位时写“交易仓盈亏比无法量化：原因（风险侧或目标侧）”，它不再等于不入场；现价上方没有强压力位时写“目标开放”。细则与复算见[权威基准](../../docs/product/策略口径与提示词规范.md)第三章及其附一、附二。

数据：财务与估值走 `GET /api/market/research?codes=…&date=目标日`，只查本机库里已有的数据，没有就写“待核：本机无该标的财务数据”。该接口一次取 1–50 只完整 A 股代码（如 `600028.SH`），`date` 必填为 `YYYY-MM-DD`，只读本库、不触发抓取或回填；根字段含 `data_source=stored`、`writes_business_data=false` 和 `items[]`。每只标的在原有 `fundamental`/`valuation` 之外新增 `fundamental_periods`（最多 8 期，按数据截至的报告日与报告期双重过滤；`as_of_date` 是最近一份包含该报告期的财报日期，不是首次披露日，只对最新一期等于实际披露日，引用时写“数据截至X日的财报”，每期带 `as_of_date_basis` 说明，附 `revenue_yoy_pct`、`net_profit_yoy_pct`、`operating_cashflow_yoy_pct` 三项累计同比，缺去年同期或零基数时为 null，样本不足 8 期时 `fundamental_history_gaps` 说明）与 `valuation_history`（`observations`、`pe_ttm`、`pb`，只用本地已有历史，有效样本少于 60 条或当前值非正时不给分位，不是全历史市场分位）。公司公告、产业消息、政策消息可以联网查，须带来源链接、发布时间和抓取时间，发布超过48小时的不算当日消息；行情、财务、估值数值不联网补。日线请求区间不短于目标日往前14个月。

2026-11-23已将A股七条实际调度提示词更新至[模板规范](../../docs/product/策略口径与提示词规范.md)v2.1、目标口径v2.0及综合研判v1.0。七条任务均已逐条回读，具体配置见[任务账本](任务账本.md)。新口径适用于更新后的投递，保留既有产物历史。

## 2026-11-16：03结论表由七列改为八列（2026-11-23起由上节的九列取代）

原因：把“等待什么结构”与正式盈亏比分开，避免低比值或待定结果缺少可追踪的观察条件。适用半导体、光伏设备、消费电子、养殖、饮料、快递、电网设备全部现有A股目录。

03固定列序：日期 / 标的 / 当前价 / 位置 / 结构关注位 / 盈亏比 / 推荐度 / 是否值得入场。

结构关注位是观察线，不是预设买点、止损或确认承接低点，不参与RR公式，不替代B0。承接未确认时取截至目标日最近20个市场交易日最低价L_watch，记录日期、价格、当日MA20及确认进度。等待左右各2日严格低点确认，其后到评估日全程未破，至少5个交易日、其中至少3日收盘高于L_watch+0.5×ATR14。满足后重新核验风险尺度及最近目标空间，再算新计划RR，不自动放行。

句式：“结构关注位：低点X元（日期）；尚缺右侧确认／守低第n日／承接收盘m日；MA20为Y元。满足承接条件后重算RR，当前不构成入场计划。”

再创新低：旧观察位明确标失效，另建带日期记录，不静默覆盖。ATR14/P>5%：“ATR14/P为x%，超过5%；等待降至≤5%，并重新核验承接及风险距离”。数据或交易日对齐不足：“待定：具体缺项”，不编价格或计数。行情条数不能冒充已核市场交易日；当前09-25日历/日线冲突的行序候选仅供待核。

评分及盈亏比执行[权威基准](../../docs/product/策略口径与提示词规范.md)，本次列变更不修改其公式、阈值及已写RR。2026-11-17按主管要求，推荐度正常发布统一为数值加百分号（如62%，取值1—100），不是概率；计算仍忠实执行权威基准的连续分项加权及最终取整S=1+floor(99W+0.5)，不改公式。缺项写“待定：具体缺项”。旧分数显示作废，以当日重算唯一行及快照为准。旧主观分、CSV及02历史点不倒填。

本契约优先于历史提示词存档中的“固定七列/不新增列”；旧提示词存档留作历史，不冒称实际调度已同步。任务正文引用本文件时采用本契约。排期与启停以实际调度为准，不因新增列改变。未经用户明确授权不自行提交Git。
