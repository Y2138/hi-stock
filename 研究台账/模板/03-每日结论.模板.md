## 当日结论

- 结论：四档之一（值得入场、可小仓试、观察、不入场），能直接判断做不做。
- 主要依据：哪几条证据，附数据日期与来源层级。
- 主要风险或下一步观察点：失效条件、待补的证据，或转多、转空条件。

## 综合研判

逐标的写，每面一到三条带日期与来源的关键证据，缺的写缺口。

| 面 | 读数 | 关键证据（日期与来源） | 缺口 |
|---|---|---|---|
| 基本面 | 利多／偏多／中性／偏空／利空／待核 | 经营趋势、盈利质量、估值、公告事件 |  |
| 技术面 | 同上 | 趋势、结构、量价、相对强弱、动能、行业与市场环境、推荐度 |  |
| 消息面 | 同上 | 公告、产业消息、政策消息、关联商品变化及传导 |  |
| 盈亏比 | 空间充足／一般／不足／超量程结构比／无法量化／目标开放 | 到最近强压力位的比值与来源、承接与风险位、波动；目标距离超过 25% 时比值后追加「（超量程结构比）」，不写空间充足 |  |

四个面不设权重，任何一项都不是门禁。推荐度、盈亏比、是否站上 MA20、承接是否确认都只作读数与证据。

## 数据缺口

- 取不到的字段逐条列出，写「缺失」，不留空、不推测。
- 评分缺必需字段写「待定：具体缺项」；盈亏比量化不了写「交易仓盈亏比无法量化：原因（目标侧或风险侧）」。
