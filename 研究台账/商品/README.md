商品侧的落点是 A 股：每个品种都要给出具体标的、当前价、相对均线的位置、盈亏比，以及今天是否值得入场。这里不给期货下单建议。

品种：黄金、铜、原油。新增品种按规定 `品种/01-标的走势.png 02-进场推荐度.png 03-每日结论.md` 三件产物齐备后再建目录，命名不另创。

## 推荐度公式（1%–100%，可复现）

`norm(x, k) = tanh(x / k)`，输出落在 −1…1。

```
t = 0.40·norm(close/MA20 − 1, 0.08)
  + 0.35·norm(close/MA60 − 1, 0.12)
  + 0.25·norm(20日涨跌幅, 0.20)

推荐度 = clip( round(50 + 49 × (0.80·t + 0.20·c)) , 1 , 100 )
```

- `t` 是股票侧技术面，`c` 是同品种主力连续用同一式子算出的商品端强弱。
- 商品端数据缺失时（当前沪金、SC 原油均缺失），权重退化为纯 `t`，必须在当日结论里注明「商品端 20% 未计入」。
- **留档从 2026-11-16 开始，不倒填。** PNG 上的长曲线是用同一公式回算的「回溯曲线」，仅作位置参照，不是当时的留档评分；真实留档以 `03-每日结论.md` 的「推荐度」列为准。

## 盈亏比公式

```
止损 = 近 20 个交易日最低价 × 0.98
目标 = 近 20 个交易日最高价
盈亏比 = (目标 − 现价) / (现价 − 止损)，写成 1:x（风险 1、收益 x）
```

止损贴着近 20 日低点时，盈亏比会算出很高的值（如 1:8），这类数字是下跌趋势里的机械结果，一根阴线就能打掉止损，解读时按当日结论里的说明来，不要只看数字。

## 是否值得入场

| 条件 | 结论 |
|---|---|
| 推荐度 ≥ 60 且收盘价 > MA20 且盈亏比 ≥ 1:2 | 是 |
| 推荐度 < 40，或收盘价在 MA60 之下且 20 日跌幅 > 15% | 否 |
| 其余 | 观察，给出具体触发位 |
