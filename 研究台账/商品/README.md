## 主推荐度公式（1%–100%，可复现）

**主推荐度只用股票侧技术面，商品端不计入主分。** 这样三个品种口径一致、可以横向比较，也符合「落点在 A 股」。

`norm(x, k) = tanh(x / k)`，输出落在 −1…1。

```
t = 0.40·norm(close/MA20 − 1, 0.08)
  + 0.35·norm(close/MA60 − 1, 0.12)
  + 0.25·norm(20日涨跌幅, 0.20)

主推荐度 = clip( round(50 + 49 × t) , 1 , 100 )
```

- 三项权重固定 0.40 / 0.35 / 0.25，不随品种变化，也没有商品端权重。
- **留档从 2026-11-16 开始，不倒填。** 2026-11-16 当天的铜是旧口径（含商品端 20% 权重），已在当日结论里注明并回改为主分口径值；`02-进场推荐度.png` 里已画的点保留旧口径、不回改，2026-11-17 起按新口径累积。
- PNG 上的长曲线是用同一公式回算的「回溯曲线」，仅作位置参照，不是当时的留档评分；真实留档以 `03-每日结论.md` 的「推荐度」列为准。

## 盈亏比公式

```
止损 = 近 20 个交易日最低价 × 0.98
目标 = 近 20 个交易日最高价
盈亏比 = (目标 − 现价) / (现价 − 止损)，写成 1:x（风险 1、收益 x）
```

止损贴着近 20 日低点时，盈亏比会算出很高的值（如 1:8），这类数字是下跌趋势里的机械结果，一根阴线就能打掉止损，解读时按当日结论里的说明来，不要只看数字。

## 是否值得入场

| 条件 | 结论 |
|---|---|
| 推荐度 ≥ 60 且收盘价 > MA20 且盈亏比 ≥ 1:2 | 是 |
| 推荐度 < 40，或收盘价在 MA60 之下且 20 日跌幅 > 15% | 否 |
| 其余 | 观察，给出具体触发位 |

## 任务拆分

一个品种一个独立任务，时间互相错开。三条硬约束：

1. **全部排在 17:00 之后**：系统每日数据获取任务在 17:00 跑，早于它取数拿到的是前一交易日数据。
2. 相邻任务至少间隔 10 分钟，避免同时抢数据源和模型。
3. 避开 18:25 `two_year_reversal_scan` 与 18:40 板块机会筛选。

| 任务名 | 品种 | 时间 | 产出目录 |
|---|---|---|---|
| `research_desk_商品_黄金` | 黄金 | 17:15 | `研究台账/商品/黄金/` |
| `research_desk_商品_铜` | 铜 | 17:25 | `研究台账/商品/铜/` |
| `research_desk_商品_原油` | 原油 | 17:35 | `研究台账/商品/原油/` |

17:00 数据任务结束到 17:15 留 15 分钟缓冲，给同步落库用；A 股三条按实际排期是 17:45 / 18:00 / 18:10，与商品这批首尾相接、互不重叠（17:35→17:45 隔 10 分钟，18:10→18:25 隔 15 分钟）。

每个任务只跑自己那一个目录，三件产物写齐；商品端缺数的品种要在 01 图标题和 03 表里都标「缺失」。调度落地（`job_definition` + 迁移）由 DM 负责，本目录只定义任务边界、时间与产出。
