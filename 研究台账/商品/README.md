# 商品研究台账

商品侧的落点是 A 股：每个品种都要给出具体标的、当前价、相对均线的位置、盈亏比、四面读数，以及今天是否值得入场。这里不给期货下单建议。

品种六个：钢、黄金、锂、铜、原油、化工。每个品种一个目录，产物按 `01-标的走势.png`、`02-进场推荐度.png`、`03-每日结论.md`、`04 评分历史` 的既有格式。

## 03 当日结论表：列固定

**九列，顺序固定**（2026-11-23 起）：日期 / 标的 / 当前价 / 位置 / 结构关注位 / 盈亏比 / 推荐度 / 四面读数 / 是否值得入场。

化工目录另加「结论分级」一列（聚氨酯、轻烃、煤制烯烃三条链各自定级），插在推荐度与四面读数之间，共十列；其余五份不加。

**结构关注位口径**（2026-11-16 新增）：

- 承接未确认时，取截至目标日最近 20 个交易日最低价 `L_watch`，注明日期；并列当日 MA20 作为修复观察线；写清确认进度（是否已过左右各 2 日严格低点确认、守低第 n 日、承接收盘 m 日）。缺哪项写哪项。
- 等待条件：该低点之后到评估日**至少 5 个交易日全程未破**，且其中**至少 3 日收盘高于 `L_watch + 0.5×ATR14`**；满足后再重算风险尺度与目标空间。
- 它只观察，不替代 `B0`、不是预设止损或买点，不进入 RR。再创新低就把旧观察位标「失效」并另建记录，不许把旧位下移后说原判断仍成立。
- `ATR14/P > 5%` 时写「ATR14/P 为 x%，超过 5%；等待降至 ≤5%，并重新核验承接及风险距离」，不只说等波动下降。
- 贴近强压力位时列出该强压力位与距离，写「盈亏比无法量化：贴近强压力位」，入场结论仍按综合研判给出。
- 数据不足写「待定：具体缺项」。

**列定义变更（2026-11-16）**：新增「结构关注位」列，位置在「位置」与「盈亏比」之间，原七列变八列（化工九列）。原因：承接未确认的标的原先只写「不成立」，读的人看不到在等什么；加这一列把观察低点、确认进度和等待条件放进表内，同时明确它不进 RR、不构成买点。公式与阈值不变，已写出的 RR 不因此改动。

**列定义变更（2026-11-23）**：新增「四面读数」列，位置在「推荐度」与「是否值得入场」之间，八列变九列（化工十列）。原因：结论改为综合研判，基本面、技术面、消息面、盈亏比四个面的读数要能一眼看到。旧行保留原文，不回改。

**四面读数与结论**（细则见 `docs/product/策略口径与提示词规范.md` 第八节）：单元格写短句，如「基本面 中性｜技术面 偏多｜消息面 待核｜盈亏比 1.6:1 到前高」，证据放正文每只标的的「综合研判」小节。「是否值得入场」是四档结论：值得入场、可小仓试、观察、不入场；结论句写结论、主要依据是哪几条、主要风险或下一步观察点。推荐度、盈亏比、是否站上 MA20、承接是否确认都不是单项门禁。

## 数据口径

取数走本机只读接口，背后是本地库；接口失败不等于缺数，先查覆盖再下结论。不记忆、不推测、不外部取数凑数。

**排序与字段契约见技术设计文档第十节 HTTP API 的接口约定**（`docs/product/Stock_策略演进系统_产品方案_v2.0.md`），本目录不重复。

| 内容 | 来源与参数 |
|---|---|
| 商品目录与覆盖 | `GET /api/futures`，看 14 个品种与每个 dataset 的 status |
| 单品种主连与日线 | `GET /api/futures/{code}?limit=80` |
| A 股代表标的日线 | `GET /api/market/bars?code=...&freq=day&start=YYYY-MM-DD&end=YYYY-MM-DD`，**必带 `start`/`end`** |
| 商品库存等因子 | `GET /api/macro/factors`，按 `series_code` 取最新期 |
| 标的检索 / 板块成分 | `/api/instruments/search`、`/api/boards/:code/constituents` |
| 财务与估值（本机库） | `GET /api/market/research?codes=…&date=YYYY-MM-DD`，一次 1–50 只完整 A 股代码，`date` 必填，只读本库、不触发抓取或回填；根字段含 `data_source=stored`、`writes_business_data=false`、`items[]`；每只在 `fundamental`/`valuation` 外新增 `fundamental_periods`（最多 8 期，按数据截至的报告日与报告期双重过滤；`as_of_date` 是最近一份包含该报告期的财报日期，不是首次披露日，引用时写「数据截至X日的财报」，每期带 `as_of_date_basis` 说明，附营收/净利/经营现金流三项累计同比 `*_yoy_pct`，缺同期或零基数为 null，不足 8 期时 `fundamental_history_gaps` 说明）与 `valuation_history`（`observations`/`pe_ttm`/`pb`，只用本地已有历史，有效样本 <60 条或当前值非正不出分位，非全历史市场分位）；没有该标的写「待核：本机无该标的财务数据」 |

公司公告、产业消息、政策消息可以联网查，每条带来源链接、发布时间和抓取时间，发布超过 48 小时的不算当日消息；行情、财务、估值等数值不联网补。

当日日线由 `daily_data_update`（cron `15 17 * * 1-5`）在 17:15 起写入、实测 17:30 结束，六条任务都排在其后。行情日期必须等于目标日，不等就标「非当日」并写实际日期。

**时效容差**：日频序列最新期与目标日相差 ≤3 个交易日、周频 ≤1 周、月频 ≤1 期。超容差按缺失或背景处理，不进当日结论、推荐度和盈亏比。

## 主推荐度

格式为数值加百分号（如 `62%`），范围 1–100，是技术观察分数，不是上涨概率、仓位比例或长线估值结论。出不了分统一写「待定：具体缺项」并在括号里点明缺的是哪一项，不写「分」「S分」这类混写。

**公式唯一权威在 `docs/product/策略口径与提示词规范.md` 第二章**（五项 A/B/D/E/F 加权后 `S = 1 + floor(99W + 0.5)`）。本文件不重复公式。

这里原先留着另一套三项 tanh 写法（`40/35/25` 加权 + `clip(round(50+49t))`），2026-11-17 六份台账就是因为它全部算错、20 条推荐度作废重算，已删除。同类情况不再在台账里存第二套式子。

- 任一必需项、行业指数、成交额门禁或价基核验失败，写「待定：具体缺项」，不出整数、不画评分点、不对剩余项重新分权重。
- 行业指数是必需项：本地序列过期或没有序列时不能出分。两类写法分别为「主行业指数过期（代码 + 最新日期 + 超容差）」和「主行业指数缺失（本地无 XX 行业指数序列）」。
- 不采用近似替代主行业指数。锂矿股曾试过用 `884286.TI` 锂电指数近似，经 PM 裁决否决：锂电指数成分含电池厂，与锂矿不等同，`884286.TI` 只作产业链背景观察、不进 F 项。锂矿五只的正式推荐度写「待定：主行业指数缺失」。要按每家公司核实唯一主行业映射，再查对应指数是否有目标日与完整 61 日序列；没有依据前不指定新代码，也不因某个指数数据齐就选它。
- 商品端不计入主分。
- **留档从 2026-11-16 开始，不倒填。** 2026-11-16 各行为旧口径，已在六份修订说明里标作废；`02-进场推荐度.png` 的历史点不回改。
- PNG 上的曲线是用同一基准公式回算的「回溯曲线」，仅作位置参照；真实留档以 `03-每日结论.md` 的「推荐度」列为准。指数缺失或过期的品种不画曲线，图内直接标待定与原因。

## 商品端佐证（不计入主推荐度）

商品数据单独列在每份 `03-每日结论.md` 的佐证表里，用来解释「股票为什么这样走」，不进入分数。各品种实际可用项（2026-11-16 实测）：

| 品种 | 主连 | 日线覆盖 | 库存 / 仓单 |
|---|---|---|---|
| 钢 | RBZL、IZL、JZL | RB ok、I ok、J partial | 三类仓单有；板材 HC、焦煤 JM 本地无 |
| 黄金 | AUZL | ok | 仓单有；结算价缺失 |
| 锂 | LCZL、LC0 | partial | 仓单序列停在 2026-09-18，超容差，只能作背景 |
| 铜 | CU0 | ok | `shfe.cu.inventory.total` 周频（2026-11-13 = 27,642 吨）；仓单有 |
| 原油 | SCZL.INE（无 SC0） | partial | 仓单有 |

硬口径三条：结算价 `settlement` 为 null 就写「缺失」，不用 close 顶替；仓单只能叫仓单，`unit` 空写「单位未披露」，不换算总库存；主连是当前成分拼接，历史不可直接外推。

主连 roll 口径要写清且不能混比：`CU0` 是「当日收盘持仓量最大，并列时按成交量和合约月排序」；`RBZL`/`LCZL`/`AUZL`/`SCZL`/`PPZL`/`MAZL` 是「供应商当前主力清单，算法未披露，不回填历史映射」。

## 盈亏比与是否值得入场

格式统一「收益:风险＝x.xx:1」，分子是同标的同计划的扣费净收益 G，分母是计划风险。**口径不在本文件重复**，权威定义见：

- `docs/product/策略口径与提示词规范.md` 第三章
- `docs/product/策略口径与提示词规范.md` 第七节

判读要点（仅为使用说明，公式以上面两份为准；2026-11-23 起按目标口径 v2.0 与综合研判口径 v1.0）：

- 目标 T 只取现价上方最近的一处强压力位：前高（回看 250 个交易日内最高的已确认高点），或成交密集区价格中枢（连续 3 个及以上、每日成交量不低于此前 20 个交易日均量 1.5 倍的交易日，取成交量加权典型价格）。MA20、MA60 与震荡高低点只作观察位，不当目标，也不因此否决。
- 现价上方没有强压力位时写「目标开放：上方无套牢密集区与前高」。目标距离 (T−P)/P 超过 25% 时，距离与比值照实显示，读数标「超量程结构比」，并注明「最近强压力位超出本口径的 20 个交易日量程提示线，比值不代表持有期内可期待的收益」；25% 是经验提示线，不是通常波幅的统计结论，不自动否决入场。
- 距离护栏：`T−P ≥ max(0.01×P, 0.5×ATR14)` 且扣费净收益 `G>0`，等号算通过、按精确值比较。不满足写「交易仓盈亏比无法量化：贴近强压力位」，正文列 P、T、目标距离百分比、ATR14、最低距离门槛，不给孤立比值；也不得越过这一处去取更远的强压力位。
- 承接未确认或风险尺度不适配写「交易仓盈亏比无法量化：原因（风险侧）」。无法量化不是不入场，结论按综合研判给出。
- 比值读数照实显示：`0<RR<1` 空间不足，`1≤RR<2` 空间一般，`RR≥2` 空间充足。目标距离超过 25% 时比值后追加「（超量程结构比）」，此时即使 `RR≥2` 也不得写「空间充足」，只写「不代表持有期内可实现收益」。读数只描述盈亏比这一面，不是入场结论。
- 商品台账的最终盈亏比必须用该 A 股标的自身的 P、ATR、结构止损与目标。期货或主连的距离只能标「商品结构观察，非股票可执行盈亏比」，不能拿来替代个股比值。

## 是否值得入场

2026-11-23 起改为综合研判，不再按单一条件查表。四个面是基本面、技术面、消息面、盈亏比，每面给读数（利多、偏多、中性、偏空、利空、待核）和带日期与来源的关键证据。四个面不设权重，任何一项都不是门禁。

| 情形 | 结论档位 |
|---|---|
| 可核实的证据多数偏多，且没有明确的利空证据 | 值得入场或可小仓试（证据面较薄取可小仓试） |
| 存在已核实的重大利空（业绩转差、政策或监管打压、放量跌破关键密集区、高影响负面公告） | 倾向不入场，并写明是哪一条证据 |
| 证据不足或相互矛盾 | 观察，写清转多条件和转空条件 |
| 没有交易权限（如创业板） | 只能观察 |

结论句固定写三样：结论；主要依据是哪几条证据；主要风险或下一步观察点。原先「RR≥2 且推荐度 ≥ 60 且收盘价 > MA20 才算是」「推荐度 < 40 或跌破 MA60 且 20 日跌幅 > 15% 算否」的查表写法同时废止；推荐度、盈亏比、MA20 位置照旧计算和展示，只作读数与证据。

## 自检点

同一标的跨目录出现时，两处必须用同源数据、同一公式重算，结果一致。若出现差异，说明公式、数据日期或口径被改动，先查口径再出表，不要为了对齐去调数。推荐度取整到 1%–100% 的整数，不出现小数。
