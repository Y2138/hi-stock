## 一、安装与调用

官方要求 64 位 Python 3.9+，推荐使用隔离虚拟环境。AKShare 不要求 Token。

```bash
python3 -m pip install --upgrade akshare
python3 -c 'import akshare as ak; print(ak.__version__)'
```

基本调用统一返回 pandas DataFrame：

```python
import akshare as ak

df = ak.stock_zh_a_hist(
    symbol="000001",
    period="daily",
    start_date="20260101",
    end_date="20260131",
    adjust="",
)
```

日期、代码和复权参数并不跨接口统一。东财 A 股接口通常用 6 位代码；新浪或腾讯接口可能要求 `sh600000`、`sz000001`。不得自行套用格式。

## 二、A股行情与标的

| 目的 | 优先接口 | 关键边界 |
|---|---|---|
| 当前 A 股代码简称 | `stock_info_a_code_name` | 当前快照，不含完整历史退市成分 |
| 当前全市场行情 | `stock_zh_a_spot_em` | 一次返回沪深京实时截面；盘中值会变化 |
| 单股日/周/月行情 | `stock_zh_a_hist` | `period=daily/weekly/monthly`；`adjust=""/qfq/hfq` |
| 单股近期分钟行情 | `stock_zh_a_hist_min_em` | 1 分钟通常仅近 5 个交易日且不复权；其他周期也有保留期 |
| 最近交易日盘前分钟 | `stock_zh_a_hist_pre_min_em` | 仅适合近期执行研究 |
| 当前 ST 股票 | `stock_zh_a_st_em` | 当前交易日名单，不是历史 ST 序列 |
| 当前退市/两网股票 | `stock_zh_a_stop_em` | 当前快照，不能消除历史幸存者偏差 |
| 个股基础信息 | `stock_individual_info_em` | 单只当前信息 |

### 复权规则

- `adjust=""`：不复权，用于核对真实成交价、涨跌停价和成交约束；
- `adjust="qfq"`：前复权，适合近期图表和技术指标，但历史值会随新除权事件改变；
- `adjust="hfq"`：后复权，适合连续收益研究，不能直接当真实成交价；
- 同一策略的价格、信号和成交应分别说明口径，不在同一列混用。

## 三、涨停连板与市场情绪

| 目的 | 接口 | 常见字段与限制 |
|---|---|---|
| 当日涨停股池 | `stock_zt_pool_em(date=YYYYMMDD)` | 连板数、首次/最后封板时间、炸板次数、涨停统计、所属行业；仅近期 |
| 昨日涨停表现 | `stock_zt_pool_previous_em` | 昨日封板时间、昨日连板数和当日表现；仅近期 |
| 强势股池 | `stock_zt_pool_strong_em` | 60 日新高、近期多次涨停等来源标签；仅近期 |
| 次新股池 | `stock_zt_pool_sub_new_em` | 上市日期、开板日期等；仅近期 |
| 炸板股池 | `stock_zt_pool_zbgc_em` | 当日触板但未封住；仅近期 |
| 跌停股池 | `stock_zt_pool_dtgc_em` | 当日跌停；仅近期 |
| 龙虎榜明细 | `stock_lhb_detail_em` | 按官方签名传日期范围；注意字段和历史可用期 |

官方实现说明：涨停专题不包含 ST 股票及科创板股票，并排除未中断连续一字涨停的新股。不能把该池直接等同于“全市场所有触及过涨停的股票”。

2026-07-23 对 `date=20260722` 的实测返回 47 行，并包含 `920305 云创退`。因此即便官方专题已做部分排除，仍必须显式应用项目交易权限、北交所/退市整理排除、ST 和上市初期过滤；不要把接口返回集直接当成可交易集合。

### 首板与连板

对 `stock_zt_pool_em`：

- `连板数 == 1` 可作为首板候选；
- `连板数 >= 2` 可作为连板候选；
- 按 `所属行业` 分组统计可构建近期板块涨停宽度；
- 使用前检查 `代码`、`连板数`、`首次封板时间`、`最后封板时间`、`炸板次数`、`所属行业` 是否存在；
- 同日数据必须在收盘后用于次日信号，不能回填为当日开盘已知信息。

### 多年回测

`stock_zt_pool_em` 官方只承诺近期数据，不适合直接循环六年日期。要研究多年打板策略，使用两条路线之一：

1. 从现在开始每日收盘归档涨停池、炸板池、股票列表、ST 名单和板块成分；
2. 用全市场不复权日线重建收盘涨停，再补充点时上市/ST/停牌/制度/行业数据。

第二条路线只能重建“收盘涨停”，不能可靠还原首次封板、开板次数、排队成交和盘中先后顺序。

## 四、行业与概念板块

| 目的 | 行业接口 | 概念接口 |
|---|---|---|
| 当前板块列表 | `stock_board_industry_name_em` | `stock_board_concept_name_em` |
| 当前成分股 | `stock_board_industry_cons_em` | `stock_board_concept_cons_em` |
| 板块日线 | `stock_board_industry_hist_em` | `stock_board_concept_hist_em` |
| 板块分钟 | `stock_board_industry_hist_min_em` | `stock_board_concept_hist_min_em` |

成分股接口主要反映当前分类。用当前成分回填历史会引入成分前视偏差；如果结论依赖历史板块归属，必须另有点时成分证据或明确降级为当前口径研究。

不同来源的行业、概念分类不可直接混合排名。输出时注明“东方财富行业”或具体分类来源。

## 五、财务估值与资金行为

先用 `search` 和 `describe` 确认当前版本函数。常用候选：

| 目的 | 候选接口 | 注意事项 |
|---|---|---|
| 三大财务报表 | `stock_financial_report_sina` | 区分资产负债表、利润表、现金流量表参数 |
| 财务摘要 | `stock_financial_abstract` | 核对报告期、累计值与单季值 |
| 财务分析指标 | `stock_financial_analysis_indicator` | 保留报告期，不用未来披露数据回填历史 |
| 个股估值指标 | `stock_a_indicator_lg` | 上游与参数可能变化，调用前确认 |
| 个股新闻 | `stock_news_em` | 新闻事实与市场解释分开 |
| 公司公告 | `stock_notice_report` | 核对公告日；点时研究只能在公告后使用 |
| 个股资金流 | `stock_individual_fund_flow` | 资金流是供应商口径，不等同真实机构持仓 |
| 板块资金流 | `stock_sector_fund_flow_rank` | 注明行业/概念及统计周期 |

财务回测必须使用公告日或可获得日。仅有报告期而没有披露时间时，不得默认报告期末数据已经公开。

## 七、历史回测的数据边界

全市场回测至少核对：

1. 历史股票全集包含退市股；
2. 上市日、退市日和停复牌状态点时有效；
3. ST 状态和不同板块涨跌幅限制点时有效；
4. 除权除息日的信号价与成交价口径一致；
5. 行业/概念成分按当时可见数据构建；
6. 收盘信号最早下一交易日成交；
7. 一字涨停买不到、跌停卖不出和最小交易单位被模拟；
8. 佣金、印花税、过户费、滑点与冲击成本完整；
9. 空表和退市数据缺失没有被静默丢弃；
10. 训练、参数选择和样本外验证按时间隔离。

AKShare 是接口层，不自动保证这些条件。缺少点时数据时，应把结果称为“信号探索”或“有偏初筛”，不能称为可成交正式回测。

## 八、接口选择与验证

推荐顺序：

```text
明确任务与口径
  -> 参考本文件选候选接口
  -> search / describe 查看本地版本
  -> 官方文档核对参数、限量、历史范围
  -> 单标的或单日冒烟
  -> 校验字段与日期
  -> 分批获取并缓存
  -> 写元数据和数据限制
```
