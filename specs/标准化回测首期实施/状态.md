# 标准化回测首期实施

- 模式：检查点
- 状态：标准日频研究运行闭环已完成；扩展数据及全市场容量未验收
- 更新：2026-09-11

## 目标与不可变边界

- 注册规则计划通过只读预检、冻结、受控执行、结算、工具和页面形成可使用的日频研究闭环。
- 数据库是唯一事实源；全市场同步由用户外部流程负责，本功能不触发同步脚本、不直接读取导出文件。
- 标准开关默认关闭，维护者显式开启；自由源码开关保持原默认开启，两条执行路径独立。
- 当前固定样本、价格制度、成本及公司行为近似全部为研究资格，不自动晋升为正式证据或发布生产策略。

## 已完成执行单元

- [x] 严格契约与迁移。
  - 负责人：当前模型。
  - 结果：类型化计划、幂等请求、运行代次及租约、输入与证据状态、事件和每日结算表；保留历史部分完成状态与正式锚点约束。
- [x] 只读预检与冻结。
  - 负责人：当前模型。
  - 结果：六年共同种子、日历、价格、股数单位、环境和可选指数基准检查；只冻结既有数据库数据；输入数据哈希与实验参数哈希分离。
  - 兼容：读取并行数据流程新增的原价列，不改写前复权生产列，不接管回填脚本。
- [x] 确定性日频内核。
  - 负责人：内核执行者，当前模型已复核。
  - 结果：共享生产右侧纯规则、流式指标、后续开盘执行、显式费用、整数分账本、退出意图、回撤及连止损熔断；纯内核不能加载服务配置。
- [x] 受控子进程与运行服务。
  - 负责人：当前模型。
  - 结果：排队立即返回；数据库单执行者领取、心跳、租约过期、取消和停止竞争处理；工作器不继承数据库或供应商凭据。
  - 结算：父进程独立核验现金、股份、费用、成本、闭环盈亏和最终收益；按日原子写入，重复批次只接受相同内容。
- [x] 基准、比较与证据边界。
  - 负责人：当前模型。
  - 结果：可选指数价格基准、收益差、共同输入与制品比较；研究最终化独立于发布资格，新策略提案不能引用未合格回测作为收益证据。
  - 重放：核验输入和运行制品内容，包含节点运行时版本；材料不齐不声称精确重放。
- [x] 智能体工具与只读工作台。
  - 负责人：工具执行者、页面执行者，当前模型已集成。
  - 结果：预检、发起、状态和取消四个工具；工作运行分页、进度、错误、曲线、事件、继续计划与比较；操作通过会话，不新增页面直接写入接口。
  - 权限：隐藏执行租约令牌和大载荷，不扩张普通每日任务工具权限，不赋予通用数据库写权限。
- [x] 数据卷与回归。
  - 负责人：当前模型。
  - 结果：完整私有备份保留冻结输入、事件与结算；固定资产白名单排除所有运行数据。

## 验证结论

- `npm run typecheck`：通过。
- `npm run web:typecheck`、`npm run web:build`：通过；存在既有前端大分块提示，不是构建失败。
- 当前工作区全量 `npm test`：十七个文件、二百五十八项通过，无跳过；包含并行数据改动的复权测试。
- 真实子进程验证：排队幂等、基线和变体、结算与基准、取消、停止领取竞争、失效令牌、过期预检、原价列选择和证据发布阻断通过。
- 浏览器真实接口验证：最终结论、工作运行、净值、事件与同口径比较正常，控制台无错误；另有慢响应下轮询、防陈旧响应和卸载清理验证。
- 容器配置及应用镜像构建：通过；只构建镜像，未重启生产应用。
- 验证使用独立容器编排项目、独立端口及临时数据库；测试容器、界面预览服务和本次临时浏览器记录均已清理，不对生产库运行测试或恢复演练。
- 本轮未执行生产迁移、数据同步、恢复、重启或策略发布。

## 当前使用方式

维护者按部署说明开启标准回测开关并更新应用后，从回测页发起标准计划。预检缺口由外部数据流程补齐；未开启时工具只报告状态，不声称已经执行。对已有失败或取消运行重试须使用新幂等键，旧记录不覆写。

## 未实现或未验收范围

- 当前预算为一百只股票、股票与环境及基准合计五十万行、压缩输入一百二十八兆字节；没有宣称五千标的多年容量已通过。
- 六年种子锚点为研究起点前六年，可能与生产当前批次的最新日锚点不同，报告明确披露。
- 完整历史交易制度、公司行为、停牌、竞价、季度财务、多策略执行以及合格证据晋升不属于已验证能力。
- 基准为指数价格序列，不是红利再投资总收益；费用和滑点为显式研究假设。

## 后续边界

研究运行闭环无需继续补入口；后续按真实数据可得性独立实施全市场容量、多策略和历史交易模型，不重建基础、不补造历史，也不把研究近似改名为正式证据。保留用户并行的回填脚本、原始价迁移及测试改动。
