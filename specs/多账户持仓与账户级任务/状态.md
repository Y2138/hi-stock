# 多账户持仓与账户级任务

- 模式：检查点
- 状态：已完成
- 更新：2026-10-08

## 任务摘要与验收

- 任务摘要：实现可命名多账户、账户级持仓和任务、共享市场与账户计划；仪表盘汇总全部账户，账户选择只影响明确标注的账户页面。
- 验收：同一标的可在多个账户独立持有；账户任务运行、会话、预案、风控和通知互不串数据；全局市场任务只执行一次；默认账户兼容现有数据。
- 不可变约束：PostgreSQL 是运行时唯一事实源；账户业务数据不进入固定资产；容器只绑定 127.0.0.1；迁移只向前执行。
- 设计文档：`specs/多账户持仓与账户级任务/评审说明.md`

## 已确认决策

- 账户使用稳定 ID 和可修改名称，归档而非删除。
- 关注池、策略、行情和市场研究保持全局；账户选择器只位于持仓页及任务中心账户任务视图。
- 仪表盘汇总全部账户，逐账户入口携带账户定位；通知默认展示全部归属并独立筛选。
- 任务中心分账户任务、全局任务；账户页面新建会话绑定当前账户；共享页面手动新建会话支持选择账户或仅全局研究，单账户自动关联，未关联普通会话可首次关联账户维护持仓。
- 缺少账户编号的旧账户任务只归入默认账户，不展示到新账户。
- 任务定义共享，账户任务通过 `job_run.account_id` 展开独立运行。
- 每日计划拆为共享市场与策略信号层、账户持仓计划层。
