## 任务摘要与验收

- 任务摘要：新增与飞书完全解耦的独立 SMTP 邮件通知通道，任务结果保存后在事务内入队，由独立 worker 将完整报告发送到固定收件人白名单；默认覆盖每周交易复盘与盘后统一标的精选，设置页支持保存、测试、清除、投递记录与失败补发。
- 验收：设置页可保存/测试/清除；任务完成后收到邮件；关闭启用后不再入队；凭据变更取消旧待发邮件；错误脱敏；`npm run typecheck`、邮件定向测试与全量回归通过，迁移可在空库与既有库向前执行。
- 不可变约束：邮件与飞书互不影响；只发送已保存的任务结果，不改写业务数据；收件人只来自设置白名单，发送时不接受任意收件人；禁止明文 25 与未加密连接；密码只存 PostgreSQL，接口只回显是否已配置；保留已有工作区改动，不提交运行数据或凭据。
- 设计文档：../../docs/design/独立邮件通知通道.md

## 已确认决策

- 邮件使用独立设置表 `email_notification_setting`、独立投递队列 `email_delivery`、独立 worker 与独立凭据版本；飞书的配置、开关、订阅和凭据变更不影响邮件，反之亦然。
- 默认任务范围为 `cross_strategy_selection` 与 `weekly_trading_review`，设置页可多选其它 `agent_flow` 任务；成功结果入队，部分完成只对默认任务或明确允许部分覆盖的任务入队。
- 任务结果保存事务内入队，一个结果最多一封邮件，重试复用同一投递记录；关闭启用后不再入队，重新开启不补推关闭期间的历史结果。
- SMTP 只支持 465 隐式 TLS 与 587 STARTTLS（强制 TLS），禁止明文 25；默认按 QQ 邮箱 `smtp.qq.com:465` SSL 配置，使用 QQ 邮箱授权码（非登录密码）。
- 主题固定为 `Stock｜任务名｜目标日`，正文为完整报告 Markdown，页脚注明结果编号、目标日与“AI 生成，不代表策略发布或交易执行”。
- 投递最多三次尝试（一分钟、五分钟退避后重试），超过一天、凭据版本变化或结果被更新版取代时取消；失败原因脱敏。
- SMTP 配置与投递记录属于本机私有数据，进入完整私有备份，不进入可移植固定资产包；换机后需重新配置并测试。
